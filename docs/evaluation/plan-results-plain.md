# 계획안별 평가 결과 — 쉽게 보기 (2026-11-10)

계획안 종류마다 「무엇을 쟀고, 결과가 어땠고, 무엇을 아직 모르는지」를 쉬운 말로 정리했다.
정확한 수치 · 조건 · 실행 기록은 [../techspec/evaluation.md](../techspec/evaluation.md)와 `runs/` 폴더에 있다.

**읽는 법**
- ○ = 그대로 쓸 만함 · △ = 고치면 씀 · ✗ = 못 씀.
- 사람 판정은 정답이 아니라 한 사람의 판정이다. 판정이 다르면 「갈렸다」고 적는다.
- AI 판정(jev · DeepEval)은 내부 참고 지표다. 계획안 저장 여부를 정하지 않고, 교사 화면에 나오지 않는다.
- 막대 한 칸(█)은 10%다.

## 한눈에

| 계획안 | 좋아진 것 (숫자로 확인) | 품질 | 아직 모르는 것 |
|---|---|---|---|
| 연간 주제형 | — (처음부터 규칙이 주제를 고름) | 사람 판정 전부 ○ | 좋고 나쁨을 가를 판정 |
| 연간 놀이 | 4배 빨라짐 · 다시 만들 때 반복 거의 없음 | 판정자마다 갈림 | 만3 · 만5 · 혼합 품질 |
| 월간 주제형 | — | 근거를 벗어난 활동 0 | 안전교육 문장 정확성 |
| 월간 놀이 | — | **안 쟀다** | 후보 글 품질 · 대피 문장 반복 해결 |
| 주간 | 앞 주와 겹침 1/3 · 활동 종류 다양 | 이전과 같음 | 주제 연결 기준 재판정 |
| 그림책 · 트렌드 | 그림책 0곳 → 매번 들어감 | 지어낸 줄거리 0 | 유튜브 트렌드 반영 |

## 1. 연간 · 월별 주제형

12달 주제는 사람이 검토한 주제 목록에서 **규칙이 고른다**. AI는 고른 주제를 문장으로 다듬기만 한다.
그래서 몇 번을 다시 만들어도 주제는 같고 문장만 조금씩 달라진다. 설계한 그대로다.

```
같은 조건 10번 생성 (칸 24개)
근거가 매번 같은 칸   ██████████  24/24
글이 매번 같은 칸     ██░░░░░░░░   5/24
```

- 사람이 직접 본 30개(연간 · 월간 주제형): 나이 · 윗 계획과 연결 · 쓸 만함 **모두 30/30 ○**. 문제가 없다는 것은 확인했지만, 좋고 나쁨을 가르는 힘은 없는 판정이다.
- 만3 · 만4 · 만5로 바꿔도 12달 주제는 같다. 목록의 12개 주제가 모두 만3~5세를 지원해서, 나이는 맞지 않는 주제를 거르는 데만 쓰인다.
- DeepEval은 돌리지 않았다. 주제를 목록에서 고르는 구조라 견줄 근거 원문이 없다.

## 2. 연간 · 놀이 중심형

1년을 계절 4구간으로 나눠 구간마다 놀이 후보 10개를 만든다. 예전(①)에는 구간을 차례로 만들었고, 지금(⑦)은 4구간을 동시에 만든다.

```
만드는 데 걸린 시간 (짧을수록 좋음)
① 예전   ██████████  149.7초
⑦ 지금   ███░░░░░░░   38.3초   (배포 서버 149.2 → 42.1초)

다시 만들 때 같은 구간에 또 나온 놀이 (40개 중, 적을수록 좋음)
① 예전   ██████████  1.91개
⑦ 지금   █░░░░░░░░░  0.15개
```

- 한 해 후보 400개 중 서로 다른 이름: 362 → 397개.
- 글 품질(2점 만점): 하민은 ① 1.30 · ⑦ 1.35, 2차 판정자 3명은 ① 1.80 · ⑦ 1.72. **판정자마다 방향이 갈렸다**(차이 0.05~0.15). 그래서 「품질이 좋아졌다」고 말하지 않고 「나빠지지 않았다」까지만 말한다.
- 대가: 구간을 따로 만드니 「놀이 이름이 분명한가」 지적이 19 → 39개로 늘었다(jev 참고 지표).
- 연령 중립 판(만3 · 만5 · 혼합 × 3회): 15회 모두 검사 통과, 2,583원.

## 3. 월간 · 월별 주제형

칸마다 「어느 기관 계획안의 어느 줄을 보고 썼다」는 근거가 붙는다. 근거는 규칙이 고르니 거의 같고(15/16 칸), 글은 AI가 쓰니 매번 다르다(2/16 칸만 같음).

「글이 근거에 없는 걸 지어냈나」를 같은 AI 판정자에게 **질문만 바꿔** 세 번 물었다. 바깥놀이 37칸:

```
                         ○ 근거 그대로    △ 덧붙임
기존 jev (6칸씩 묶음)     ████░░░░░░  14 / 23
DeepEval 넓은 질문        ░░░░░░░░░░   0 / 37
DeepEval 좁힌 질문        ███████░░░  27 / 10
                         (✗ 다른 활동은 세 방식 모두 0)
```

- 넓은 질문은 「활동을 풀어 쓴 말」까지 덧붙임으로 봐서 전부 △가 됐다.
- 「근거에 없는 새 재료 · 노래 · 작품 이름이 있나」로 좁히자 △ 10만 남았다. 10개 모두 「물레방아 돌리기」에 「물」을 붙인 같은 경우다. 물레방아라면 당연한 재료라 문제로 볼지는 사람마다 갈릴 수 있다.
- **안전교육 후보**: 사람이 본 5개 모두 ○. 법정 6개는 공식 문항에서만 고르고 근거가 정확히 1개인지 서버가 검사한다. 문장의 정확성을 따로 크게 판정하지는 않았다.

## 4. 월간 · 놀이 중심형

**글 품질은 재지 않았다.** 반복만 쟀다. 반복을 재 보니 안전 · 대피 칸이 가장 많이 겹쳤다.

```
대피 후보 (실측 30회 · 코드 확인)
5개 중 화재                  ████████░░  4/5
화재 문장 쌍 끝이 같음        ██████████  96%  (「…대피하는 연습을 해요」)
거의 같은 문장이 나온 회차    ███░░░░░░░  10/30
연속 두 달 대피 묶음이 같음   ███████░░░  8/11
```

- 법을 어긴 것이 아니라 **후보 목록이 단조로운** 문제다. 법정 재난대비 문장과 대피 후보는 서로 겹치지 않는다(최대 유사도 0.09).
- 원인: 대피 주제는 「그 달 한정 주제 먼저, 나머지는 목록 순서로 5개」를 골랐다. 연중 주제가 화재 4 · 지진 1뿐이라 봄 · 가을엔 늘 같은 5개다.
- 고침(2026-11-11 하민 결정): **달마다 돌리기** — 연중 주제의 시작점을 학년도 달마다 한 칸씩 옮긴다. 같은 묶음 8/11 → 3/11(코드 계산). 봄 · 가을 달끼리는 순서만 다르고, 한 계획안 안 화재 4개는 그대로다.
- 남은 후보(결정 전): 문장 끝맺음 다르게 · 앞 달 안전 항목 피하기 · 안전 항목 학년도 순환. 「화재 2개까지」는 「대피 후보 5개」 결정과 충돌해 뺐다.

## 5. 주간

교사가 고를 활동 후보 10개가 나온다. 예전엔 매주 **똑같은 10개**가 나왔다. 지금은 앞 주에 쓴 것을 뒤로 미루고 20개 중에서 섞어 뽑는다.

```
앞 주와 겹치는 후보 비율 (실내놀이, 낮을수록 좋음)
이전          ██████████  1.00
미루기        ███░░░░░░░  0.32
최종(+섞기)   ████░░░░░░  0.35   활동 종류 7.0 · 「기타」 81 → 15

사람이 본 최종 후보 51개 (○ 비율)
나이에 맞나          ████████░░  0.82
월 주제와 이어지나   ██████░░░░  0.55   (이전과 같은 수준)

근거를 벗어났나 — 후보 651개 (jev)
○ 311 · △ 334 · ✗ 6   (✗ 6개는 사람이 다시 보니 모두 「같은 활동」으로 갈렸다)
```

AI 판정이 하민 판정과 같은 비율 (근거 대조 26개):

```
기존 jev             ██░░░░░░░░   6/26
DeepEval 넓은 질문   ███░░░░░░░   8/26
DeepEval 좁힌 질문   ████████░░  22/26   (3회 모두 같음)
```

- 좁힌 질문은 하민이 ○라 한 20개를 하나도 잘못 걸지 않았다. 놓친 4개는 풀어 쓴 덧붙임이라 이 질문이 일부러 세지 않는 종류다.
- **이 26개를 보고 질문을 고쳤다.** 다른 표본으로 다시 확인해야 한다.
- 비용: 주간 1회 생성 중앙값 약 89원 · 26~28초. DeepEval 판정 1개 약 0.04원.

## 6. 그림책 · 트렌드

그림책을 쓸지 말지 AI에게 맡겼더니 한 번도 쓰지 않았다. 규칙이 「이 자리에 이 책」을 정해 주자 매번 들어갔다.

```
AI가 고르게 둠        ░░░░░░░░░░    0/168곳   (1,258원)
규칙이 자리 배정      ██████████    6/6회     (1,334원)
지어낸 줄거리         0/6 (사람 관찰 · DeepEval 모두)
유튜브 트렌드 반영    0회 — 주제와 맞는지 거르는 규칙이 아직 없다
```

- 그림책은 저작권 때문에 제목만 넘긴다. 그래서 설명이 단조롭다 — 줄거리를 지어내지 않는 대가다.
- 트렌드는 언제나 가점이다. 파일이 없거나 원이 꺼 두면 트렌드 없이 그대로 만든다.

## 7. 평가를 어떻게 했나 · 교사 설문

- **사람**: 어느 회차인지 가리고 ○ · △ · ✗. 하민 1명 + 2차 판정자 3명. 사람끼리도 주제 판단은 크게 갈렸다(같은 판정 0.49).
- **jev**: 「이 활동이 근거 원문과 같은가」 같은 질문에 확률로 답하는 판정 모델. 글을 쓰지는 못한다.
- **DeepEval**: 공개 평가 도구. 질문 여러 개를 jev에 묻고 점수를 모은다. 우리 서버의 jev 호출 방식에 맞춘 연결 부품만 만들었고 서비스 코드는 고치지 않았다. 총 12.52원, 사용 통계 전송은 껐다.

교사 설문 17명 (5점 만점, 괄호 = 4점 이상 응답 수):

```
AI 초안 후 교사가 확정하는 방식   ████████░░  4.12 (14/17)
연간 → 월간 → 주간 단계별 작성    ███████░░░  3.71 (11/17)
확인 · 수정이 편함                ███████░░░  3.59 (9/17)
형식 · 항목이 맞음                ███████░░░  3.35 (7/17)
활동 · 주제가 쓸 만함             ███████░░░  3.35 (8/17)
```

## 8. 결론과 아직 안 잰 것

「빨라졌다」 「덜 반복한다」는 숫자로 확인했다. 「글이 더 좋아졌다」는 말하지 않는다 — 판정자마다 갈렸다.
대신 틀리면 안 되는 것(근거 · 나이 · 안전 · 법정 기준)은 서버 검사로 막아 두었다.

아직 안 잰 것:
- 놀이 월간 후보 글 품질 · 트렌드를 쓴 후보의 품질.
- 안전교육 · 대피 문장의 정확성과 연령 적합(사람이 본 안전 후보는 5개뿐).
- 「안전교육 빼라」 같은 요청이 막히는지 실측(레드팀) — 지금은 코드 구조 표만 있다.
- DeepEval 좁힌 질문을 다른 표본에서 다시 확인.
