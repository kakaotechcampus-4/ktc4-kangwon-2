# 평가 근거

평가 항목마다 문서 한 장. **주장 옆에 근거를 붙인다.**
근거는 커밋 · PR 번호 · ADR · 코드 경로 중 하나다. 근거 없는 줄은 적지 않는다.

## 심사가 둘이다

| | 무엇 중심 | 항목 | 이 폴더와의 관계 |
|---|---|---|---|
| **멘토 심사** | 기술 · 개발 | 10개 · 100점 | **우리 10장과 1:1** |
| **현장발표 심사** | 제품 · 발표 · 사업성 | 6개 · 100점 | 3개만 겹친다 |

### 현장발표 심사 — 셋은 겹치고 셋은 발표 자료 몫이다

| 배점 | 항목 | 어디서 |
|---:|---|---|

**③ Agentic 경험은 양쪽에 다 있다 — 합쳐 30점으로 한 항목 중 제일 크다.**
그런데 관점 문구가 「**사람이 끼어들지 않아도** 끝까지 풀어내는가」다.
우리는 일부러 교사가 확정 버튼을 누르게 만들었다. [03](03-agentic-experience.md) 이 그 답을 들고 있어야 한다.

## 쓰는 법

한 줄에 **주장 하나 + 근거 하나.**

```
- 아동 실명이 LLM 프롬프트에 안 간다 — `backend/app/shared/childCode/` · ADR-004 · ADR-013
```

- **근거는 저장소 안의 것만.** 개인 문서 · 브랜치에만 있는 문서는 인용하지 않는다 (ADR-031).
- **아직 아닌 것을 숨기지 않는다.** 각 파일에 그 칸이 있다. 비워 두면 평가 때 질문으로 돌아온다.
- 「더 모을 근거」는 체크박스다. 남은 작업 목록으로 쓴다.
