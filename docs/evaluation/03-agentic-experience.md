# 03 · Agentic 경험 — 교사가 겪는 AI

**멘토 심사 기준(기술·개발 중심) ③ Agentic 경험 — 10점**

> 여러 도구와 단계를 스스로 엮어, 사람이 끼어들지 않아도 핵심 시나리오를 끝까지 풀어내는가

**현장발표 심사기준(제품·발표·사업성 중심) ③ Agentic 경험 — 20점**

> 여러 도구와 단계를 스스로 엮어, 사람이 끼어들지 않아도 핵심 시나리오를 끝까지 풀어내는가

---

## 사람이 안 끼어드는 구간 — 교사가 버튼 하나 누르면 여기까지 혼자 간다

```
교사가 「만들기」를 누른다
  │
  ├ 근거 모으기      누리과정 · 주제 참고자료 · 상위 계획안 · 활동 참고자료 · 기관 자료 ·
  │                 행사 달력 · 안전 규칙 · 트렌드 — 12종에서 그 문서에 필요한 것만
  ├ 아동 코드 치환    실명을 더미 이름으로. 실패하면 호출하지 않고 멈춘다
  ├ 프롬프트 구성     문서 단위 배치 — 연간 12개월 · 월간 한 달 · 주간 한 주를 한 번에
  ├ LLM 호출         `shared/llm/client.py` 한 곳을 지난다
  ├ 1 스키마 게이트   칸 이름 · 개수가 틀리면 반려
  ├ 수리 재호출       반려된 칸만 다시 만든다 (`repair_scope_issues`)
  ├ 2 추출 대조       이름 · 수량 · 날짜를 원문과 문자열 비교. 모델 안 부름
  ├ 3 LLM Judge      사실 · 해석 · 지원 관계 검사
  ├ 저장 + 출처 기록   칸마다 Evidence · Generation · Audit
  └ 검증 리포트       무엇이 통과하고 무엇이 반려됐는지 (ADR-037)
```

**여기까지 사람 손이 하나도 안 들어간다.** 도구가 여럿이다 — 참고자료 검색 · LLM ·
규칙 엔진 · 아동 코드 치환 · 양식 파서(`hwp5html`) · hwpx 생성기 · 트렌드 수집기.
어느 하나가 실패해도 다음 단계가 알아서 받는다(수리 재호출 · 선택 입력 건너뛰기).

**스스로 이어지는 자리도 있다.**

- 연간을 확정하면 **월간이 연간을 근거로 받아 간다.** 교사가 옮겨 적지 않는다 (ADR-030 PM-04)
- 일과 기록을 고치면 **그걸 근거로 쓴 보육일지가 스스로 「다시 보세요」로 바뀐다.** 교사가 기억할 필요가 없다 (ADR-025 · ADR-040)
- 트렌드봇은 채널을 **혼자 돌며 모으고 거르고** 승인 대기함에 쌓는다 (ADR-016)

## 멈추는 자리는 하나다 — 확정 버튼

```
교사가 적는다   관찰 한 줄 · 일과 기록          ← AI 가 사실을 만들지 않는다
AI 가 만든다    위 전 과정을 혼자 돌아 초안(DRAFT)
교사가 정한다   고치고 확정 버튼(CONFIRMED)      ← 자동 제출 · 자동 발송 없음
```

**왜 거기서 멈추나.** 보육 문서는 **원이 제출하고 평가인증에 쓰는 서류**다.
교사 이름으로 나가는 종이에 교사가 안 본 문장이 실리면, 틀렸을 때 책임질 사람이 없다.
**자동화를 못 한 게 아니라 거기까지만 자동화하기로 정했다** — [CLAUDE.md](../../CLAUDE.md) §생성 · §문서 5분류

- 결과는 `DRAFT` 로 저장되고 **교사가 눌러야** `CONFIRMED`
- 계획안은 층마다 순차 게이트. 연간이 확정 아니면 월간을 못 만든다 — ADR-030 PM-04

## 왜 이렇게 나왔는지 교사가 볼 수 있다

- **출처를 칸 단위로 기록한다.** 세 축을 한 값에 섞지 않는다 — [CLAUDE.md](../../CLAUDE.md) §생성 · PR #15 ·
  `p0-planning/src/ssuksak/planning/domain/provenance.py` (`EvidenceSourceType` 12개 · 값이 코드와 문서가 같다)

  | 축 | 묻는 것 | 값 |
  |---|---|---|
  | Evidence | 이 값이 어디서 왔나 | 누리과정 · 주제 참고자료 · 상위 계획안 … 12개 |
  | Generation | 어떻게 만들어졌나 | `RULE_ONLY` · `RULE_LLM` · `IMPORTED` · `MANUAL` |
  | Audit | 나중에 무슨 일이 있었나 | `CREATED` · `REGENERATED` · `TEACHER_EDITED` · `CONFIRMED` |

- **「AI」는 출처가 아니라 제조 방법이다.** 교사에게 "AI 가 만들었습니다"는 판단에 도움이 안 된다 —
  AI 가 만든 값도 근거는 누리과정·주제·상위 계획안이다 — 같은 곳
- 교사가 고쳐도 Evidence 를 지우지 않고 `TEACHER_EDITED` 이벤트를 **더한다.** 되돌리기와 평가제 집계가 거기서 나온다
- **출처 표시는 화면에만.** hwp 내보내기에 마커가 섞이면 안 된다 — 제출 문서다

## 손대지 않는 문서가 있다

문서를 5분류로 가르고 **AI 개입 한계를 분류마다 다르게 뒀다** — [CLAUDE.md](../../CLAUDE.md) §문서 5분류

- 알림장 · 사고보고서 · 투약의뢰서는 **사실기록형**. **AI 가 쓰면 위조라서 생성 기능을 안 붙였다**
- 법정교육 이수기록은 **추적형**. LLM 이 아니라 카운터·날짜 계산이다

「다 해준다」가 아니라 **해주면 안 되는 자리를 먼저 정했다.**
