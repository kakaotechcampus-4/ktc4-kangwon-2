## 통과 조건을 먼저 정했다 — 3층 규격

```
① 사실   교사가 입력한 관찰 사실.  AI 가 추가 못 함
② 해석   ①에 있는 사실만 근거로
③ 지원   다음에 어떻게 지원할지
```

- **②가 ①에 없는 사실을 쓰면 반려**
- **③이 비면 반려**
- [CLAUDE.md](../../CLAUDE.md) §3층 규격 · ADR-024 `024-journal-three-layers-merge-on-paper.md`

**왜 이 세 칸인가** — 같은 판매자의 두 자료에서 평가어가 60배 차이 났고, 차이는 「해석과 평가」 칸의 유무뿐이었다
([docs/미확정사항.md](../미확정사항.md) L80). 칸 구조가 교사의 글을 바꾼다는 실측에서 나왔다.

## 품질에 손대지 않기로 한 것

- **평가제 자체점검은 누락 탐지만.** 통과 판정을 LLM 이 하지 않는다 — ADR-019 · ADR-022
- 규칙 엔진은 **고르는 게 아니라 검사한다** — ADR-014

## 실제 모델로 한 번 돌렸다 — 주간계획안 (2026-10-21)

[docs/weekly-llm-live-smoke-20261021.md](../weekly-llm-live-smoke-20261021.md) · 측정 하민 · 모델 `openai/gpt-6-luna`(엘리스)

| 항목 | 값 |
|---|---|
| 요청 | 9 (생성 5 · 한 칸 재생성 4) |
| 저장 성공 | **9 / 9** · HTTP 200 × 9 — strict 형식을 모두 받았다 |
| 수리 | **0 / 9** |
| 비용 | **₩11.03** (상한 ₩1,000) |
| 시간 | 생성 8.5~22.4초(중앙 9초) · 한 칸 재생성 4.1~5.6초 |

사람이 본 것 — 연령·계절·주제가 맞았고, 토요일을 켠 반에서 요일을 지어내지 않았고,
날짜·이름을 지어내지 않아 **Q2 차단이 한 번도 안 걸렸다(오탐 0)**.
거슬린 것은 한 칸의 「지난해」 하나 — 교사가 고칠 범위다.

**여기서 버그를 찾았다** — 바깥놀이 「다시 만들기」가 같은 활동을 돌려준다(F-1).
재생성 때 지금 활동을 순위에서 뒤로 미루지만 LLM 후보 목록에는 남아 있어 모델이 다시 골랐다.
**mock 으로는 안 나왔을 종류다.**

**문장 원문을 문서에 안 옮겼다.** Golden 으로 오해되면 모델이 쓴 문장을 기대값으로 굳히게 된다 — ADR-023.

## 아직 아닌 것

- **일지 4종(보육일지 · 관찰일지 · 영유아 평가)은 real 로 한 번도 안 돌렸다.** bench 스크립트가 계획안 쪽에만 있다
- 월간 bench 스크립트는 있는데 **결과 문서가 없다** — 돌렸는지 확인 필요
- 품질이 「사람이 본 요약」이고 **채점표가 없다.** 몇 점인지 말할 수 없다
- 교사가 "이건 못 쓰겠다"고 한 사례를 모은 적이 없다
