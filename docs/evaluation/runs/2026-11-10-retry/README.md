# LLM 재시도 경로 실제 모델 확인 (2026-11-10)

ADR-076 「모델에 닿지 못한 요청만 1회 재시도, 폴백 없음」을 실제 모델로 확인했다. 로컬 실험 서버의 LLM 주소를 로컬 프록시로 돌려 처음 N번에 503을 주고 그 뒤는 실제 주소로 전달했다. 호출은 주제형 연간 1회(만4). 비용 46원(입력 11,140 · 출력 1,011 토큰, VAT 별도).

| 경우 | 프록시 | LLM 시도 (`llm_call` outcome) | 결과 | `plan_timing` |
|---|---|---|---|---|
| 두 번 연속 503 | 503 · 503 | `not_delivered` · `not_delivered` (1.5초 간격) | `500 GENERATION_FAILED` 5.7초 | `outcome=http_500 llm_calls=2` |
| 한 번 503 → 전달 | 503 · 200 · 200 | `not_delivered` · `ok` · `ok` | `201 DRAFT` 12달 24.7초 | `outcome=ok llm_calls=3` |

- 재시도는 실행 기록에 `llm_calls`(시도 수)로 남고, 실패한 시도도 `llm_call` 한 줄로 남는다. 별도 retry 필드는 없다.
- 두 번째 실패는 폴백 없이 500이다. 교사 문구 「계획안을 만들지 못했습니다. 다시 시도해주세요.」
- 응답 중 끊김은 모델이 이미 돌았을 수 있어 재시도하지 않는다(`RETRY_STATUSES` = 502 · 503 · 504, 연결 거부, 주소 조회 실패). 이번에는 시험하지 않았다.
- 응답 원문 · 서버 로그는 올리지 않았다. 키 · 주소는 어디에도 쓰지 않았다.
