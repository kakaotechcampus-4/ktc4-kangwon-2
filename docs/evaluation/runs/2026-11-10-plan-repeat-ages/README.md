# 주제형 연간 · 월간 — 만3 · 만5 조건 추가 (2026-11-10, 배포 develop `d1ef53e5`)

지금까지 주제형은 만4세만 쟀다(`../2026-11-08-plan-repeat/`, `../2026-11-10-plan-repeat-after/`). 같은 조건(11월 · 요청 사항 없음)으로 **만3세 · 만5세를 3회씩** 더 만들었다. 요청 36회 모두 성공, 비용 어림 약 550원(연간 약 23원 · 월간 약 69원 × 6).

- **12달 모두 `theme_id`가 같다.** 연령별로 다른 것은 LLM이 쓴 표현(「따뜻한 봄」 ↔ 「봄」)뿐이다.
- 이유: Theme Reference v0.1.2의 12개 Theme이 모두 만3~5세를 지원하고, Rule은 「그 달에 적용 가능하고 반 연령을 모두 지원하는 후보」 중 고르므로 연령이 선택을 바꾸지 않는다. 설계대로이며 위반은 아니다(CLAUDE.md §14 「선택된 Theme가 classroom의 전체 연령 집합을 지원」).
- **기록할 한계:** 연간 단계에서 「연령 적합성」은 *필터*로만 작동하고 *차별*은 하지 않는다. 연령 차이는 월간 근거(아래)와 주간 후보에서 나타난다. 연령별로 다른 Theme를 주려면 Theme Reference에 연령별 후보를 더해야 하는데, 이는 사람 검토가 필요한 Reference 변경이라 마감 뒤 과제다.

|---|---|---|---|---|
| 만3 | 2 | 2 | 14/16 | 5/16 |
| 만4 | 5 (앞 3회) · 6 (10회) | — | 12/16 (10회) | 1/16 (10회) |
| 만5 | 5 | 4 | 13/16 | 1/16 |

- 만3 월간은 쓸 수 있는 근거가 2건뿐이다 — 만3 단일연령 11월 기록이 근거 창고에 적다(주간 시뮬레이션에서도 같은 경향). 생성은 실패하지 않고(모두 201) 글은 LLM이 달리 쓴다.
- 반복 겹침 · 한 계획안 안 중복은 만4와 같은 범위다(`a3_analysis.md` · `a5_analysis.md`).

## 3. 아직 아닌 것

- 사람 판정은 만4(30개)만. 만3 · 만5 글은 판정하지 않았다.
- 혼합연령(만3+4 등)은 측정 스크립트가 단일 연령만 받아 이번엔 못 돌렸다.
