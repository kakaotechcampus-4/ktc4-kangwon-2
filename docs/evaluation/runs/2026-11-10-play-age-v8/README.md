v8 은 ADR-090(놀이를 연령으로 나누지 않는다 · `ages` 는 위험하거나 맞지 않는 재료를 거르는 데만 쓴다, PR #504)이다.
하민 승인(2026-11-10, 상한 10,000원)으로 돌렸고, **실제 쓴 돈은 2,583원**(호출 60회)이다.

**생성 글은 기대값(Golden)이 아니다.** 실행 기록으로만 둔다(ADR-023). 회수가 조건마다 3회뿐이라 아래 숫자는 경향을 보는 정도로만 읽는다.

## 1. 연령으로 나뉘는가 — 같은 구간에서 연령끼리 겹침

회 A 의 후보 40개마다 같은 구간의 회 B 후보에 **같은 이름**(공백 · 부호 무시) 또는 **비슷한 놀이**(서비스 겹침 검사 `similar_play_names` — 이름, 또는 이름 + 준비물)가 있는지 셌다. 회 쌍 평균이다.
**같은 연령 안 회끼리** 줄이 기준선이다 — 생성마다 Rule 힌트(`play_seeds`)를 무작위로 뽑으므로 같은 연령이어도 겹침이 낮다.

## 무엇을 말할 수 있고 무엇은 아직인가

- **말할 수 있다**: v8 로 바꿔도 계약(검증 통과 · 재호출 · 겹침)과 시간 · 비용은 v7 과 같은 수준이었다(조건마다 3회).
- **말할 수 있다**: 두 판 모두 놀이 이름 · 글에 연령 낱말을 쓰지 않았고, 연령끼리 이름 겹침은 같은 연령 회끼리와 같은 수준(거의 0)이다.
- **아직이다 — 연령 중립성**: 이 측정으로는 v7 과 v8 이 갈리지 않았다. 무작위 힌트가 겹침을 지배해서 지표가 판별력이 없다. 확인하려면 같은 `play_seeds` 로 연령만 바꿔 짝 비교를 해야 한다(제안, 별도 승인 필요).
- **아직이다 — 안전**: 큰 위험 낱말(구슬 · 건전지 · 자석 · 유리 · 불 · 바늘)은 0건이었다. 혼합반의 「강낭콩」, 크기 표시 없는 「돌」(v7 만3), 「테이프 커터」(v7 만3), 「보온병」 「주전자」(v8 혼합)는 목록으로만 남긴다 — 판단은 사람 몫이다.
