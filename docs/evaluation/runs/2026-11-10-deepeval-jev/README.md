# DeepEval JevEval — 계획안 후보 근거 충실도 판정 (2026-11-10 밤)

DeepEval 4.3.3 의 `JevEval` 지표로 생성 후보가 근거를 벗어났는지 쟀다. 하민 승인: 「어느 결과에 돌릴지는 판단해서」. 상한 100원 → **5.04원**(120건, jev ₩62/1M 입력).

판정은 내부 품질 지표다. 저장 여부 · 합격을 정하지 않고 교사 화면에 띄우지 않는다(CLAUDE.md §5). 하민 판정도 한 사람의 판정이라 「갈렸다」로 적는다.

## 어떻게 붙였나

- `JevEval(name, evaluation_params=[INPUT, ACTUAL_OUTPUT, RETRIEVAL_CONTEXT], questions=[...])` — 질문마다 jev 확률을 받아 가중 평균을 낸다. LLM 은 안 쓴다.
- DeepEval 기본 `TypeSafeModel` 은 typesafe 키가 필요하다. 그래서 `DeepEvalBaseSystemOneModel` 을 상속한 `ElicJev` 가 질문을 우리 `/v1/decisions` 형식으로 바꿔 `app.shared.llm.client.decide` 로 보낸다. 서비스 코드는 고치지 않았다.
- 사용 통계 끔(`DEEPEVAL_TELEMETRY_OPT_OUT=1`), `evaluate()` 를 안 써서 Confident AI 업로드 없음. 기관 이름은 ○○ 로 가렸다.
- 테스트 케이스: `input` = 판정 기준 + 월 주제 · 칸 · 종류, `actual_output` = 「활동명: 설명」, `retrieval_context` = 근거 원문.

### 질문

| 지표 | 질문 | 타입 |
|---|---|---|
| 근거 충실 | E1 근거 원문과 같은 활동인가 | Noul |
| | E2 근거에 없는 구체적 재료 · 도구 · 진행 · 사실 · 다른 활동이 있는가 | Choice 그렇다 0 · 아니다 1 |
| | E3 없는 내용이 있다면 활동명에서 바로 떠올릴 흔한 진행 정도인가 | Noul |
| 그림책 충실 | B1 근거 그림책을 함께 읽는 활동인가 | Noul |
| | B2 제목 · 부제만으로는 알 수 없는 줄거리 · 인물 · 사건이 있는가 | Choice 그렇다 0 · 아니다 1 |

E1~E3 문장은 기존 `weekly_jev_evidence_judge.py` 그대로다(견주려고). E2 는 「그렇다」가 나쁜 쪽이라 Choice 점수로 뒤집었다. ○/△/✗ 는 기존 규칙(E1<0.5 ✗ · E2<0.5 ○ · 아니면 E3≥0.5 △ / ✗, 0.3~0.7 이면 애매).

## 어디에 돌렸나

| 묶음 | 건수 | 왜 |
|---|---|---|
| 주간 최종 | 51 | 현재 동작(tier 섞기 제거 후) 주간 후보 |
| 근거 재확인 | 26 | 하민이 근거와 대조해 판정한 표본 — 일치도를 볼 수 있는 유일한 묶음 |
| 월간 바깥놀이 | 37 | 월간 주제형 바깥놀이(기관 근거 인용) |
| 그림책 | 6 | ADR-072 그림책 자리 실측 6회 |

뺀 것: **연간**(THEME_REFERENCE 라 대조할 근거 원문이 없다), **놀이 계획안**(근거 인용 구조 · 기준이 다르다), 에이전트 지표(Task Completion · Tool Correctness — 계획안 생성은 고정 흐름이라 맞지 않는다).

## 관찰 (정답 아님)

- **그림책은 지어낸 줄거리 0건.** B2 0.03~0.05, 6/6 ○. 앞 실측의 사람 관찰과 같다.
- **현재 동작 주간 후보에 「다른 활동」(✗) 0건.** E1 은 51건 모두 0.79 이상.
- **E2 질문은 쓸모가 적다.** 「활동명: 설명」은 한 줄 근거보다 늘 말이 많아 jev 가 거의 다 「덧붙임 있음」으로 본다. 하민이 문제 삼은 덧붙임(악기 · 노래를 넣은 것, 「책으로 표현」 등)과 흔한 풀어쓰기를 E3 도 가르지 못했다. 이 질문 세트로는 ○/△ 비율을 품질 숫자로 쓰지 않는다.
- **한 건씩 묻기가 6건 묶음보다 E2 를 높게 본다**(월간 기존 ○14 → △). 반대로 E3 는 높아져 엉뚱한 ✗ 가 줄었다.
- **같은 입력 두 번에 값이 흔들린다.** j001 은 시험 호출에서 E2 0.56(△), 본 실행에서 0.47(○). 0.5 근처 판정은 한 번으로 믿지 않는다.

## 다음에 할 수 있는 것 (하민 결정)

- E2 를 「근거에 없는 **재료 · 도구 · 다른 활동 이름**이 있는가」처럼 좁히고, 진행 방법 풀어쓰기는 빼 다시 묻기 — 하민 △ 6건을 가르는지 26건으로 먼저 확인(약 1원).
- CI 에 붙이려면 FakeLLM Golden 이 아니라 별도 수동 실행으로 둔다(유료 · 비결정).
