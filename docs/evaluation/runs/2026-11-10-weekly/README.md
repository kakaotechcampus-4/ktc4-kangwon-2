# 주간 후보 반복 실측 — 앞 주 근거 미루기 · 섞어 뽑기 · 종류 순환 (2026-11-08 ~ 11-10)

주간계획안의 대·소집단 · 실내놀이 후보가 같은 주를 다시 만들 때, 그리고 같은 달 주끼리 반복되는 문제를 고친 기록이다.
개선의 흐름은 [docs/techspec/improvement.md](../../../techspec/improvement.md) §2에, 측정 방법은 [evaluation.md](../../../techspec/evaluation.md)에 있다.
코드는 #469로 develop에 머지됐다.

**생성 글은 기대값(Golden)이 아니다.** 테스트는 이 문장을 비교하지 않는다(ADR-023).

## 이 폴더에 없는 것 · 이유

- 응답 원문(생성 글 · 인용 근거 글 · 서버 로그)은 저장소에 올리지 않았다. 근거 자료의 기관 정보를 가명으로 바꾸기(ADR-079, #465) **전에** 만든 것이라 원 기관 정보가 섞여 있을 수 있다.
- 여기에는 글 없이 숫자만 모은 결과와, 호출 없이 다시 도는 시뮬레이션만 둔다.

## 조건

- 모델 Sol · 로컬 서버 · 반 하나 → 연간(월별 주제형) 확정 → 월간 확정 → 주간.
  - 만4 · 11월(4주)
  - 만5 · 12월(5주, 대·소집단 근거가 7건뿐인 칸)
- (가) 그 달 모든 주를 1주부터 한 번씩 만든다. 앞 주 근거가 다음 주로 넘어간다.
- (나) 1주를 10번 「만들기 → 저장 → 지우기」 한다.
- **질의는 모든 주에 같은 월 주제다.**
  - 대·소집단 후보는 원래 월 주제로만 검색한다(ADR-054).
  - 실내놀이는 소주제도 쓰지만, 이 월간에는 소주제 칸이 없었다.
- 「지금」 쪽은 새로 부르지 않았다. develop 11-08 같은 주 10회와 11-09 「앞 주 빼기만」 실측 값을 쓴다. 만5 · 12월의 「지금」은 결정적이라 계산값이다.
