## 누구의 어떤 문제인가

- 만 3~5세 유아반 담임교사. 지어낸 사람이 아니라 실측으로 적었다 — [docs/페르소나.md](../페르소나.md)
- 근거 라벨을 `[실측] / [판단] / [미확인]` 셋으로 가르고, **[미확인]을 근거로 기능을 정하지 않는다** — 같은 문서 §근거 표기
- 혼합 연령 반이 흔하다 — [실측] 충북 연간계획안 18건 중 7건(39%)
- 문서를 혼자 쓰고 결재란이 「담임 / 원장」 둘뿐이다 — [실측]

## 시나리오

- 화면 단위 흐름 — [docs/screen-spec.md](../screen-spec.md) (일지 S-J1~7 · 계획안 S1~11)
- 멘토 파일럿용 클릭 경로 — [docs/mentor-pilot-guide-2026-10-21.md](../mentor-pilot-guide-2026-10-21.md)
- 교사가 쓰는 재료는 셋뿐이다 — 빠른 기록 · 관찰 기록(`observations`) · 일과 기록(`routines`).
  거기서 문서 4종이 나온다 — [docs/api-spec.md](../api-spec.md) §11

## 아직 아닌 것

- **실제 교사 파일럿을 아직 못 했다.** 2026-10-21 점검은 로컬 · `LLM_MODE=mock` · 가상 아동이었다
  ([docs/mentor-pilot-guide-2026-10-21.md](../mentor-pilot-guide-2026-10-21.md) §진행 전 상태)
- 영유아 평가 양식 실물을 한 장도 못 봤다 — [docs/미확정사항.md](../미확정사항.md) U-3
