`label_derivation`은 대부분 "구분 기호 정규화"라고 기술하지만, 실제로는 **일부
연령의 근거에 없는 개념이 라벨에 포함된 경우**가 있다. 아래 5건은 사람이 판단해야 한다.

### NHJ-1 `봄과 동식물·자연` (4월)

| 근거 | 원문 라벨 | `자연` 포함 |
|---|---|---|
| 서충주 p.1 만3세 | `봄/동식물과 자연` | ✅ |
| 서충주 p.2 만4세 | `봄·동식물과 자연` | ✅ |

| 예담 만3·4세 | `봄 느껴보기` | ❌ |
| AP 만5세 | `봄이 왔어요` | ❌ |

- **현재 값**: label `봄과 동식물·자연`, derivation "구분 기호만 정규화"

- **문제점**: derivation이 "구분 기호만"이라고 하지만 만5세 근거에는 `자연`이 없다. 또 `봄/동식물과 자연` → `봄과 동식물·자연`은 어절 재배치를 포함한다
- **추천 수정안(제안)**: (a) label을 `봄/동식물과 자연`으로 대표 샘플 원문에 맞추거나, (b) `label_derivation`을 "만3·4세 라벨 기준, 만5세는 `자연` 미포함"으로 정직하게 기술

## 6. HR-04 적용 범위 과장 여부 — 12/12 PASS [실측]

### applicable_months

12개 theme 전부 `applicable_months`가 evidence에 관찰된 월 집합과 **정확히 일치**한다.
과장 0건, 축소 0건.

```
단일 월 10개: [3][4][5][6][7][8][11][12][1][2]
복수 월  2개: 우리나라와 세계 [9,10] / 가을과 자연 [9,10]
```

### age_conditions

12개 theme 전부 `supported_ages: [3,4,5]`이며, **각 연령에 대한 독립 근거가 존재**한다.
서충주가 만3·4·5세를 **각각 별도 페이지**로 제공하기 때문이다.

```
supported=[3,4,5]  evidence_ages=[3,4,5]   → 12/12 OK
```

즉 "만3세 4월 근거로 만3·4·5세 3~5월을 커버"하는 식의 과장은 **없다**.

단 `yr_theme_winter_play_health`는 연령 커버 자체는 근거가 있으나 **만5세 근거의
의미가 라벨과 다르다**(§5 NHJ-5). 이는 HR-04가 아니라 HR-03 문제로 분류했다.

### 공식 문서가 월별 주제 근거가 아님을 실측 확인

`보건복지부 고시 제2019-152호` 전문 용어 빈도:

| 용어 | 출현 |
|---|---:|
| 주제 | **0** |
| 생활주제 | **0** |
| 소주제 | **0** |
| 연간 / 월간 / 주간 / 일일 | **0 / 0 / 0 / 0** |
| 계획 | 2 |
| 편성 | 6 |

**공식 누리과정은 월별 주제를 전혀 규정하지 않는다.** 따라서 `curriculum_links`를
"4월의 국가 표준 주제는 봄"으로 해석할 근거가 없고, 현재 JSON도 그렇게 쓰지 않는다.

### ⚠️ 오독 위험 1건 — 사람 인지 필요 [출처]

서충주 p.1의 주제 열 **머리글이 `누리주제`**다(p.2·p.3은 `주제`).
기관이 자체적으로 붙인 열 이름이지만, 후속 검토자가 이것을 **"누리과정이 정한
주제"로 오독**할 수 있다. 실제로는 기관의 열 이름일 뿐이며 공식 근거가 아니다.

`normative_status: SAMPLE_DERIVED_NON_NORMATIVE`가 이 오독을 막는 장치이므로
**유지되어야 한다**.

## 8. 9월 / 10월 Flexible 영역 특별 검토

### 관찰된 배치 [실측]

| 기관 | 9월 | 10월 |
|---|---|---|
| 서충주 만3세 | `우리나라/세계 여러나라` | `가을/자연` |
| 서충주 만4세 | `세계 여러 나라` | `가을과 열매` |
| 서충주 만5세 | `우리나라/세계 여러 나라` | `가을/자연` |
| 예담 만3·4세 | `우리나라 알아보기` | `가을 느껴보기` |
| AP 만5세 | `우리나라` | `무르익는 가을` |
| **소답 만3~5세** | **`가을`** | **`우리나라`** |

**소답만 순서가 반대다.** 4개 기관 중 3개는 9월=우리나라 / 10월=가을이고,
소답은 9월=가을 / 10월=우리나라다.

### applicable_months 반영 정확성 [실측]

| theme | applicable_months | evidence 월 분포 |
|---|---|---|
| `우리나라와 세계 여러 나라` | `[9, 10]` | 9월 5건 · 10월 1건(소답) |
| `가을과 자연` | `[9, 10]` | 10월 5건 · 9월 1건(소답) |

**두 theme 모두 `[9,10]`이 관찰된 월 집합과 정확히 일치한다.** 과도한 일반화가 아니다.
한 달로 고정하지 않은 것이 근거에 부합한다.

### Rule Engine과의 관계 [실측]

현재 선택 Rule은 `evidence_strength_for_month`(해당 월 evidence 개수)를 쓴다.
따라서 9월은 `우리나라와 세계`(5 vs 1), 10월은 `가을과 자연`(5 vs 1)이 선택된다.
**다수 관행을 따르되 소답형 순서도 후보로 남아 있다.**

### 판단이 필요한 지점 [판단]

소답 1건을 근거로 두 theme을 각각 9·10월 양쪽에 적용 가능하게 둔 것이
적절한지는 사람 판단이다. 두 가지 해석이 가능하다.

- **유지**: 실제로 순서가 다른 기관이 존재하므로 유연성이 근거에 부합한다
- **축소**: 1개 기관 1건을 근거로 양방향 허용은 과한 일반화일 수 있다

축소를 택하면 9·10월 각각 후보가 1개로 줄어 재생성 여지가 사라진다는 점을
함께 고려해야 한다.

## 10. JSON 수정 제안 (미적용)

**아래는 제안일 뿐이며 JSON을 수정하지 않았다.** 승인 시 별도 지시를 기다린다.

### 우선순위 높음

1. **`yr_theme_winter_play_health`** — `theme_id`에 `health`가 있으나 label에 없고,
   만5세 근거는 `건강과 안전`이다. label·id·근거 삼자가 어긋난다. 셋 중 하나로
   정렬해야 한다.
2. **`label_derivation` 문구 교정** — NHJ-1·NHJ-3은 "구분 기호만 정규화"라고
   기술되어 있으나 실제로는 일부 연령 근거에 없는 개념을 포함한다. 문구를
   실제 파생 과정에 맞게 고치는 것이 안전하다.

### 우선순위 중간

3. **소답 `여러 가지 직업` evidence** — 주제/소주제 계층을 구분하는 필드를 추가하거나
   해당 항목을 제거한다.
4. **오독 방지 주석** — 서충주 p.1의 열 이름이 `누리주제`라는 사실과, 그것이 공식
   근거가 아니라는 점을 catalog 주석에 남긴다.

### 변경하지 말아야 할 것

- `normative_status: SAMPLE_DERIVED_NON_NORMATIVE` — 유지
- `applicable_months` — 전부 근거와 정확히 일치하므로 변경 불필요
- `age_conditions` — 전부 독립 근거가 있으므로 변경 불필요
- `curriculum_links` — 역할·페이지 매핑 모두 정확
- `catalog_version` · `source_version` — 내용 변경 시에만 새 버전 발행

**내용을 수정하면 `catalog_version`을 새로 발행해야 한다**(CLAUDE.md §8:
"Theme Reference 내용이 변경되면 기존 version을 덮어쓰지 말고 새 version을 발행한다").
그 경우 12개 theme의 `source_version`과 Golden Set의
`yearly.reference.catalog_version_exact` 기대값도 함께 갱신 대상이 된다.
