# 쌤플 디자인 그림

파일을 열지 않고도 무엇이 그려져 있는지 알 수 있게 적어 둔다.

**참고용이다. 앱은 이 PNG 를 읽지 않는다.** 화면의 포스티는 `frontend/components/app/Posty.tsx` 가
SVG 로 그리고, 파비콘은 `frontend/app/icon.svg` 다. 그림을 고쳐도 코드가 따라오지 않고, 코드를 고쳐도
그림이 따라오지 않는다.

파일 이름의 `tone-` · `pose-` 뒷부분은 `Posty.tsx` 의 `tone` · `pose` 값과 같다. 이름으로 코드를 찾으면 된다.

## 포스티

쌤플의 얼굴. **노란 쪽지가 몸**이고(오른쪽 아래 귀퉁이가 접혀 있다), 가는 검은 팔과 둥근 큰 손발이
쪽지에서 바로 나온다. 얼굴은 점 눈 둘과 웃는 입.

- **상체와 얼굴 크기는 어느 그림에서나 같다. 팔다리 각도만 바뀐다.** 몸을 새로 그리면 같은 아이로 안 읽힌다.
- **색이 곧 상태다.** 빨강은 진할수록 되돌리기 어려운 일이다.
- **아이를 나타내는 그림이 아니다.** 서비스가 교사에게 말을 거는 자리에만 선다.

포스티 그림은 모두 **240 × 281px, 흰 바탕**이고 몸통이 같은 자리에 있다. 겹쳐 놓으면 팔다리만 달라 보인다.

## 색 여덟 — `tone-*.png`

모두 서 있기 포즈 · 기본 얼굴이다. 쪽지 색만 다르다.

| 파일 | 쪽지 색 | 뜻 | 토큰 |
|---|---|---|---|
| `tone-note.png` | 노랑 | 기본 얼굴. 사이드바 쪽지 | `--pg-note` |
| `tone-sage.png` | 세이지 초록 | 끝난 것 · 확정 | `--pg-sage` |
| `tone-shell.png` | 연회색(사이드바 색) | 비어 있음 · 조용한 자리 | `--pg-shell` |
| `tone-sun.png` | 크림(테두리 황토) | 안내 · 알아 두면 좋은 말 | `--pg-sun-tint` |
| `tone-lilac.png` | 연보라 | 고른 것 · 지금 보고 있는 것 | `--pg-primary-tint` |
| `tone-caution.png` | 연한 빨강 | 가벼운 주의 | `--pg-alert-soft` |
| `tone-check.png` | 중간 빨강 | 확인이 필요한 일 | `--pg-alert` |
| `tone-erase.png` | 진한 빨강 | 지우기 · 되돌릴 수 없음 | `--pg-alert-strong` |

코드에는 그림이 없는 `plum` · `clay` 가 더 있다. 사이드바에서 작은 장을 겹쳐 「여러 장」으로 보일 때만 쓴다.

## 포즈 아홉 — `pose-*.png`

모두 노란 쪽지다. 상체와 얼굴 자리는 그대로, 팔다리 각도만 바뀐다.

| 파일 | 생김새 | 쓰는 때 | `face` |
|---|---|---|---|
| `pose-stand.png` | 두 팔을 비스듬히 아래로. 점 눈 · 웃는 입 | 기본. 목록 · 빈 화면 옆에 선다 | `base` |
| `pose-up.png` | 두 팔을 머리 위로(만세). 눈웃음 | 저장했어요 · 확정했어요 | `done` |
| `pose-hand.png` | 한 팔만 번쩍 위로. 찌푸린 눈썹 · 일자 입 | 잠깐 — 지우기 · 되돌릴 수 없는 일 | `fix` |
| `pose-point.png` | 한 팔을 비스듬히 위로 뻗어 가리킴 | 여기를 보세요. 처음 쓰는 길 안내 | `base` |
| `pose-wave.png` | 한 팔을 굽혀 머리 옆으로(인사) | 첫 인사 · 로그인 직후 | `base` |
| `pose-cheer.png` | 두 팔을 어깨 위로 벌리고 다리도 벌림(신남). 눈웃음 | 오늘 할 일을 다 끝냈을 때 | `done` |
| `pose-run.png` | 팔은 앞뒤로, 다리는 크게 벌려 뜀 | 만드는 중 · 기다리는 화면 | `base` |
| `pose-think.png` | 눈을 내리감고 일자 입, 한 손을 얼굴 쪽으로 굽혀 올림 | 묻는 화면. 고르라고 할 때 | `think` |
| `pose-sit.png` | 쪽지가 낮게 내려앉고 다리를 옆으로 벌림(쉬기). 점 눈 · 동그란 입 | 아직 아무것도 없어요 | `empty` |

## 화면에서 쓰는 조합 넷 — `combo-*.png`

포즈 · 색 · 얼굴을 묶어 둔 것. 이 조합만 쓰면 어디서 만나도 같은 아이로 읽힌다.

| 파일 | 언제 | 생김새 | 코드 값 |
|---|---|---|---|
| `combo-warning.png` | 지우기 전 | 진한 빨강 쪽지 + 손 들기 + 놀란 얼굴(올라간 눈썹 · 동그란 입) + 오른쪽 위 빨간 느낌표 | `erase` · `hand` · `oh` |
| `combo-done.png` | 확정 직후 | 세이지 쪽지 + 신남 + 눈웃음 + 오른쪽 위 보라 반짝(`+` 둘) | `sage` · `cheer` · `done` |
| `combo-empty.png` | 기록이 없을 때 | 연회색 쪽지 + 쉬기 + 동그란 입 | `shell` · `sit` · `empty` |
| `combo-greeting.png` | 첫 화면 | 노란 쪽지 + 인사 + 머리에 붙인 종이테이프 | `note` · `wave` · `base` + `tape` |

**느낌표와 반짝은 `Posty.tsx` 에 없다.** 그림에만 있는 장식이다. 화면에 넣으려면 컴포넌트에 그려야 한다.

## 마크와 아이콘 — `brand-*.png`

흰 바탕이고, 원본 시트가 1배 크기라 포스티 그림보다 작다.

| 파일 | 생김새 |
|---|---|
| `brand-wordmark.png` | 지금 쓰는 워드마크. 베이지 둥근 카드 위에 보라 굵은 `Ssample` + 끝에 황토색 점, 그 아래 손글씨 「쌤플」 |
| `brand-icon-current.png` | 파비콘 · 앱 아이콘 **지금 안**. 크림색 둥근 네모 위에 보라 세리프 `S` + 주황 점. `icon.svg` 와 같다 |
| `brand-icon-option-a.png` | 아이콘 **제안 가**. 같은 네모 위에 보라 별표 `*` |
| `brand-icon-option-b.png` | 아이콘 **제안 나**. 보라 세리프 `S` + 황토 점 |
| `brand-icon-asterisk-sizes.png` | 제안 가의 별표를 32 · 24 · 16px 로 줄여 나란히 놓은 견본. 작아져도 읽히는지 보는 그림 |
