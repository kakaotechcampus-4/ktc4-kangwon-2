```
무엇        「술술 쓰는 관찰일지 (어린이집ver.) — 유아」 구조·작동방식 설명서
누가        소리네공방 — 유치원 · 어린이집 교사 카페.  카페 매니저가 만들었다
받은 날     2026-10-15 (PM)
등급        [참고]   실물 양식이 아니다.  원본 전문은 팀 드라이브에
```

## 이 자료의 격 — 무엇의 근거이고 무엇의 근거가 아닌가

**현장 교사를 상대로 실제로 돌아가는 도구다.** 교사가 안 쓰면 그 카페에서 바로 드러난다.
그 점이 우리 표본(원 2곳 · 11건 · 대부분 영아)보다 낫다.

| | 이 자료 | 우리 #124 실측 |
|---|---|---|
| 교사가 무엇을 빠뜨리나 | ✅ 12문항이 그 목록이다 | |
| 교사가 받아들이는 출력 모양 | ✅ 실제로 쓰고 있다 | |
| 평가제에서 안 걸리는 문장 규칙 | ✅ | |
| **원 양식의 칸 구조** | ❌ 챗봇 출력이지 양식이 아니다 | ✅ 실물에서 떴다 |
| **「기본생활습관」 행이 있나** | ❌ 답이 없다 | ✅ 여기서만 나온다 |

**`U-1a` 를 풀지 못한다.** 관찰일지 종이에 칸이 몇 개인지는 여전히 모른다.

만든 쪽도 「실제 내부 소스코드나 비공개 시스템 지침의 원본은 아니며, 현재 기능과 개선을 위한
설계 제안을 구분해 수록했다」고 밝혔다. **설계 제안 쪽은 그쪽의 바람이지 현장 사실이 아니다.**

## 우리가 가져온 것

### ① 거절 규칙 네 줄 → `api-spec §11`

```
교사가 실제로 하지 않은 개입
진단명 · 가정 판정 (ADHD · 자폐 · 언어지연 · 애착장애 · 가정환경 · 양육 태도)
근거 없는 변화 · 성장 서술
가족사 · 건강 · 그 밖의 개인정보
```

### ② 사실을 적는 순서 → `FR-404`

**상황 → 행동 → 반응 → 교사 지원 또는 이어진 변화**

그쪽은 질문 12개를 **하나씩** 던져서 이 순서를 채운다. 우리는 사실 칸이 하나뿐이라
**칸을 늘리는 대신 이 순서를 입력칸 안내로 보여준다.**

### ③ 연령별 관찰 초점 · 분량 → 생성 프롬프트

```
만3세   놀이 선택 · 말로 표현 · 감정의 구체화
만4세   협력 · 역할 조정 · 감정 조절의 시도
만5세   규칙 이해 · 협상 · 문제 해결
분량    관찰 3~5문장 · 해석 2~4문장 · 전체 6~9문장
```

## 우리 결정을 떠받치는 것

**ADR-024 가 유아 쪽에서 한 번 더 확인됐다.** 그쪽 **유아** 출력이 두 덩어리다.

```
[관찰 내용]   자유놀이 시간, 지안이는 블록영역에서 ...
[해석]       ... 반복되는 쌓기와 무너뜨리기 과정을 통해 ...
             ... 환경과 언어적 지원이 필요해 보인다.      ← 지원이 해석 끝 문장에 붙는다
```

**해석 칸과 지원 칸이 따로 없다.** 우리가 B원 **영아** 실물에서 본 것(「평가」 한 칸에
해석 + 지원)과 같은 모양이다. 영아 한 곳으로 정했던 결정에 유아 사례가 하나 붙었다.
