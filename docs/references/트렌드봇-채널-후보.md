# 볼 때 다섯 가지만 본다

채널 하나에 **30초**면 된다. 하나라도 ❌ 면 뺀다.
**1번은 눈으로 못 가린다** — 넣고 첫 수집 결과로 가린다.

### 1. 아동용 표시는 **눈으로 판정하지 않는다**

검열 1단은 `madeForKids` 를 본다. 그런데 그 값은 **영상마다 따로** 붙고
(`sources.py:_with_video_status`), API 로만 보인다. **채널 단위로 눈으로 가릴 수 없다.**

```
❌ 「댓글이 없으니 아동용이다」     제작자가 손으로 끈 것일 수도 있다
❌ 「이 영상에 댓글이 있으니 탈락」  다른 영상은 아동용일 수 있다
```

**그러니 여기서 판정하지 말고 넣어 보고 확인한다.** 첫 수집을 돌린 뒤
**건진 게 0건인 채널을 뺀다.** 1단에서 다 떨어졌다는 뜻이다.

`made_for_kids` 는 표시가 없으면 `None` 이다 — 코드가 「아동용이 아니다」와 「모른다」를
일부러 가른다(`sources.py:97`). 눈대중으로 둘을 섞지 않는다.

### 2. 만 3~5세인가

```
❌ 영아용   까꿍 · 딸랑이 · 기저귀 · 이유식
❌ 초등용   구구단 · 받아쓰기 · 코딩
✅ 유아용   자유놀이 · 역할놀이 · 바깥놀이 · 만들기 · 동요 · 율동
```

### 3. ★ 교사가 옮겨 적을 게 나오나 — 제일 중요

영상 하나 열고 **「이걸 보고 계획안 활동 칸을 채울 수 있나」**를 본다.

```
✅  "신문지로 공을 만들어 바구니에 던지기 — 필요한 것: 신문지, 바구니"
❌  장난감 개봉 · 상품 소개 · 아이가 노는 걸 보여주기만
```

**장난감 리뷰 채널은 구독자가 아무리 많아도 뺀다.**

### 4. 얼마나 자주 올리나

최근 영상 날짜를 본다. **한 달에 한 편이면 주 1회 수집에 긁을 게 없다.**

### 5. 한국어인가

같은 브랜드도 한국어 채널이 따로 있다 — `@pinkfong` 은 영어, `@핑크퐁` 이 한국어다.

# 뉴스 언론사 4곳

전부 열어서 확인했다. **`www.` 를 뗀 것**을 적는다 — 기사의 `originallink` 와 대조한다.

```yaml
news_outlets:
  - name: 베이비뉴스
    domain: ibabynews.com     # 임신·출산·육아 전문
  - name: 베이비타임즈
    domain: babytimes.co.kr
  - name: 키즈맘
    domain: kizmom.com
  - name: 소년한국일보
    domain: kidshankook.kr
```

**뉴스는 놀이 소스가 아니다**(ADR-016). 「공룡이 유행이다」까지만 알려주고 노는 법은
안 알려준다. **소재 발굴과 「진짜 유행 맞나」 확인용**이다.

# 뺀 것과 그 이유

| 뺀 것 | 왜 |
|---|---|
| 보람튜브 · 서은일상 · DuDuPopTOY · ToyPuddingTV | 구독자 1,000만대인데 **장난감 개봉**이다. 교사가 옮겨 적을 게 없어 검열 3단에서 떨어진다 |
| `@토이푸딩` · `@간니닌니` · `@토이트론` | 같은 이유 |
| `@주니토니` | 동요 채널이라는데 **채널 설명이 「캐리·캐빈 장난감」**이다. 확인 전까지 보류 |
| `@pinkfong` · `@tayo` · `@babybus` | 실재하지만 **영어 글로벌 채널**이다 |
| `@아이코리아` | 실재하지만 아이코리아TV 가 **아니다**. 진짜는 `@aicorea_tv` |

**50개를 채울 수는 있었다.** 장난감 채널을 넣으면 금방 된다. 안 넣었다 —
ADR-016 이 「승인 채널 20~30개」로 잡아둔 숫자가 지금 29개와 맞고,
3단에서 떨어질 것을 넣으면 API 호출만 쓴다.

# 고른 뒤에 할 일

```bash
# 1  ID 를 채운다. 손으로 적지 않는다
YOUTUBE_API_KEY=... python backend/scripts/resolve_channels.py @cjkidsstory @핑크퐁 ...

# 2  찍힌 줄을 approved-sources.yaml 의 youtube_channels 에 붙인다
# 3  news_outlets 는 위 네 줄을 그대로 쓴다
# 4  그 PR 이 승인 절차다 (ADR-016 결정 5 — 관리자 화면을 만들지 않는다)
```

**첫 수집 뒤에 한 번 더 거른다.** 채널별로 건진 건수를 세서 **0건인 채널을 뺀다** —
`madeForKids` 표시가 없거나 내용이 안 맞아 1단·3단에서 다 떨어진 것이다.
눈으로 못 가리는 것을 여기서 가린다.

**이야기·책을 유튜브로만 채우지 않는다.** ADR-016 이 주력을 **도서관 정보나루**,
보조를 네이버 책으로 정해 뒀다. 그쪽은 채널 승인과 무관하다.
