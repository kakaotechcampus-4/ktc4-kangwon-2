# ADR-053: 주간 요일 양식의 승인 자료·부모 월간 연결

- 상태: 제안 — 로컬 구현, 교차 리뷰 대기
- 일자: 2026-11-01
- 범위: 주간 Template v0.2.0의 LLM 생성·칸 재생성. 기존 v0.1.0 경로는 유지한다.
- 선행: ADR-032(Rule/LLM 경계), ADR-033(주간), ADR-049(v1 누리과정 맥락), ADR-051(요일 칸).

## 배경

월간은 기관 근거로 음식 놀이를 작성할 수 있지만 주간은 Catalog ID/label만 골라 같은 놀이를 이어가지 못했다. 주별 대·소집단 근거도 비슷한 월 주제 표현에 쏠렸다. 하민은 2026-11-01 기존에 분석·가공한 공식 자료와 Reference, v2·v1 연/월간 작성 기준 및 부모 월간 연결을 함께 활용하도록 지시했다.

개별 자료 승인·Template 승인·운영 설정 변경을 이 지시로 대신하지 않는다.

## 구현한 방향

1. 같은 주 부모 월간의 현재 놀이와 focus를 먼저 읽는다. 부모 값은 PARENT_PLAN 근거와 칸 스냅샷으로 추적한다. 교사 수정값도 우선하되 원 기관 자료가 수정 문장 전체를 보증한다고 표시하지 않는다.
2. 바깥놀이는 기존 Catalog ID/label 경로와 함께, 승인된 바깥놀이 근거 또는 부모의 현재 바깥놀이를 바탕으로 쓰는 경로를 허용한다. 후자는 reference_id=null이다. 기관 근거를 생략할 수 있는 것은 정규화한 값이 부모 현재 값과 같은 경우뿐이며, 다른 문장은 허용된 바깥놀이 기관 근거를 인용해야 한다. Catalog ID를 만들거나 수정 문장을 기존 ID의 이름으로 위장하지 않는다.
3. 자유 문장 바깥놀이의 자체 연령 적합성은 기존 검증처럼 NOT_VERIFIED로 알린다. Catalog의 지원 연령 검사를 통과했다고 표시하지 않는다.
4. 주간 분류 근거 검색은 월·연령·품질·승인 분류·기관 상한을 유지한다. 해당 주 focus에서 여러 주에 공통인 2-gram을 덜어 검색하며, 남는 조각이 없으면 기존 질의를 쓴다. 어휘 검색은 의미 검증이 아니다.
5. 누리과정 59개는 기존처럼 교육적 맥락이다. v2의 승인 생활 문장 15개는 기본생활습관·건강·영양의 표현 참고로 제공한다. 부모 습관을 대체하거나 새 활동 인용 ID로 사용하지 않는다. 예문 그대로 복사도 기존 복사 검사에 포함하며, 부모 현재 값의 정당한 계승은 허용한다.
6. 생활 Catalog가 미승인·누락 상태이거나 누리과정 판/ID가 맞지 않으면 provider 호출과 저장 전에 중단한다. 서버는 이 자료 로드·대조 실패만 기존 503 DEPENDENCY_UNAVAILABLE로 변환한다. 자료와 무관한 요청 조립 오류는 변환하지 않는다.
7. v2의 기존 자연스러운 놀이 설명 원칙을 공통 상수로 재사용한다. v2 프롬프트 바이트는 유지한다. 주간 설명은 기존 v2의 합니다체, 활동명·목표·생활 문장은 기존 각 역할의 기준을 따른다. 새 글자 수 상한·금지어·문장 시작 다양성 검사는 만들지 않는다.
8. 실내대체는 같은 주 바깥 경험을 이어가고 허용 근거로 이어갈 수 없으면 기존 빈칸 경로를 사용하도록 안내한다. 그 의미상 적합성을 Rule이 판정한다고 주장하지 않는다.

## 자료의 역할

| 자료 | 역할 |
|---|---|
| 승인 누리과정 Catalog | 교육적 맥락. 새 활동/도구 허용 목록 아님 |
| 기관 Evidence + 월간/주간 분류 | 칸별 활동 근거. 월·연령·품질·분류 범위 유지 |
| Activity Catalog | 고를 수 있는 바깥놀이의 안정된 ID와 이름 |
| 교사 확정 월간 | 이번 주의 현재 주제·놀이·생활·안전 기준과 출처 |
| 승인 생활 문장 Catalog | 표현 참고. v2의 문장 선택·저장 계약을 주간에 이식하지 않음 |
| 안전 Rule·분류·품질 | 월간 후보/배치 및 주간 안전 복사·검증의 기존 경로 |
| 승인 훈련 Catalog | 기존 월간 후보 생성에 사용. 주간 일정·훈련 칸을 자동 신설하지 않음 |
| R1 검토표·생태 사례 색인 등 조사 자료 | 사람 검토와 후속 자료화 후보. 미승인 runtime 근거로 주입하지 않음 |

## 호환성과 버전

- 주간 생성 기본값 v0.1.0, 운영 모델·전송·타임아웃, API 응답 필드, DB schema, HWPX는 그대로다.
- 요일 양식 요청에만 `+monthly-linked-v2`를 기존 DAY 꼬리표 앞에 붙인다. 생성·수리·칸 재생성·재생성 수리에 모두 적용한다.
- 생활 Catalog ID/판과 예문, 허용 근거는 요청에 포함돼 request fingerprint에 반영된다. 생성된 칸에는 실제 프롬프트 판을 기록한다. 전체 요청을 계획안의 새 영구 필드로 저장하는 변경은 아니다.
- 기존 계획의 값·근거·아이템 ID·교사 편집 이력은 자동 변환하지 않는다. 기존 v0.1.0 Golden 기대값은 바꾸지 않는다.

## 한계

이 연결은 허용된 근거를 공급하고 부모를 이어 쓸 수 있게 한다. 같은 주의 경험을 의미상 잘 연결하는지, 주 사이의 놀이가 충분히 다양한지는 보장하지 않는다. 동일 이름 검사만으로 의미 중복을 판정하지 않으며 새로운 LLM Judge를 도입하지 않는다.

관련 구현: `generate_weekly_plan.py`, `weekly_lifecycle.py`, `retrieval/weekly.py`, `planner/weekly.py`, `adapters/weekly_composition.py`.

## 후속 보완 — 부모 실내대체의 적격 인용 유지 (2026-11-04 하민 승인)

요일 양식에서 부모 월간의 같은 주 실내대체가 비어 있지 않으면, 그 칸이 인용한 기관 기록을 주간 후보에서 우선한다. 이 우선순위는 기존 품질·주간 분류·대상 월·연령 확인을 통과한 기록에만 적용하고, 상위 10개·기관당 제한을 유지한다. 부모의 문장만으로 근거를 대신하지 않으며, 맞는 허용 근거가 없으면 기존 빈칸 정책을 따른다. 다른 주나 다른 칸의 인용은 자동으로 가져오지 않는다.

검색 후보가 바뀌므로 연결 꼬리표는 `+monthly-linked-v7`로 구분한다. 구판 요청의 검색과 Golden은 그대로다. 이 보완은 주간 문장이 의미상 항상 부모 활동과 일치한다는 보장이 아니다.

2026-11-06(하민 결정): 실내놀이 쓰기 예시를 `[역할놀이] - 활동명: 짧은 설명`에서 `[역할놀이] 활동명: 짧은 설명`으로 바꿨다(후보 복사 값 `[영역] 이름`과 같은 모양, ADR-054). 프롬프트 글이 바뀌므로 꼬리표를 `+monthly-linked-v8`로 올린다. 검색 후보는 v7과 같다.
