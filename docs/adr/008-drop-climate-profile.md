# ADR-008: 기후 프로파일 기능을 삭제한다

- 2026-09-06
- 상태 — 폐기 (기능 삭제)

## 맥락

이전 아이디어(「나가도 될까」 — 실외놀이 판정 서비스)에서 넘어온 기능이 셋 있었다.

```
F7    당일 나갈까 판정 (날씨·미세먼지 API)
F7a   계획 시점 기후 프로파일 — "9월은 비가 잦으니 대체안을 미리 준비하세요"
F8    판정 결과를 문서에 자동 기입
```

F7a 를 P0 층 우선순위의 5번째 층으로 넣어뒀다.

## 결정

- **F7a 삭제.** P1 도 아니고 없앤다.
- F7(당일 판정)은 **P1** 로 이동. 일지 기능이다.
- F8 은 **P0 유지, 축소.** 「판정해서 넣기」가 아니라
  **계획안에 이미 적힌 대체안을 일지로 값 복사.** LLM·API 를 안 부른다.
- 층 우선순위를 6단 → **5단**으로 줄인다(기후 층 제거).

## 근거

**실측이 근거를 무너뜨렸다** `[실측]`

월간계획안 실물 5장을 파싱했더니 **모든 주 칸에 바깥놀이가 채워져 있고
옆에 `[대체놀이]` 가 항상 같이 적혀 있었다.** 빈 주가 없다.

```
풀잎반 3주   봄바람을 느껴요        / [대체놀이] 뒤뚱뒤뚱 균형잡기
풀잎반 4주   봄 내음을 느껴요       / [대체놀이] 친구에게 공 전달놀이
```

교사는 **날씨와 무관하게 대체안을 미리 쓴다.**
"9월은 비가 잦습니다"를 알려줘도 행동이 바뀌지 않는다. **하는 일이 없는 기능이다.**

**주간계획안에도 예보를 쓰지 않는다** `[판단]`

"주간은 단기라 예보가 나오니 계획이 바뀌지 않나"라는 질문이 있었다.
바뀌지 않는다 — 바깥놀이 칸이 본활동과 대체를 둘 다 담으므로
날씨가 어느 쪽이든 쓸 글자가 같다.

그리고 주간계획안은 전주에 미리 쓰므로 예보 대상이 3~8일 후다.
강수 적중률이 3일 이후 급락한다. **틀린 예보로 계획을 바꾸면 안 바꾼 것보다 나쁘다** —
교사가 계획과 다르게 실행하고 그 차이를 일지에 또 설명해야 한다. 문서 작업이 늘어난다.

## 남긴 것 — 지역

기후와 지역 특성은 다른 얘기다. **지역은 살아 있다.** `[출처]`

제4차 표준보육과정 — *"지역 수준의 다양성 ... 지역사회의 상황과 여건을 고려하여
보육과정을 특색 있게 운영"*.

지역사회 연계 활동(전통시장·도서관·소방서 견학)의 근거다.
**별도 기능이 아니라 선별 층 4순위 「원 특성」 축**이고 P0a 안에 있다.

## 결과

- 층 우선순위 5단 — 법정 → 행사·달력 → 연간 주제 파생 → 5영역 균형 → 트렌드
- 바깥놀이·대체는 층이 아니라 **모든 주 칸의 고정 슬롯**이다.
- F8 반영 대상은 **월간계획안 · 보육일지 2곳**이다. `[실측]`
  주간계획안은 국가 공시 대상이 아니고 원마다 형태가 달라 제외했다.
- 「지역」 필드의 용도가 기후 판정에서 지역사회 연계 활동 + 양식 추천으로 바뀌었다.

## 교훈

기능의 값은 「정보를 준다」가 아니라 **「행동을 바꾼다」로 검증한다.**
실물을 안 보고 「이게 필요하겠다」로 층을 하나 만들었고, 실물 5장이 그걸 지웠다.
