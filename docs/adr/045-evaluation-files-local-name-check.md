# ADR-045: 평가 서류는 교사 컴퓨터에서 파일 이름만 보고 센다

- 2026-10-28
- 상태 — 제안
- 관련 — ADR-022(보충) · ADR-019 · ADR-013

## 맥락

평가 준비 화면은 쌤플에서 확정한 문서만 센다(ADR-022). 교사는 쌤플 밖에서 쓴 일지 · 면담 기록 · 이수증도 평가에 낸다.
팀 회의(2026-10-28)에서 「서버로 올리지 말고, 교사 컴퓨터에서 파일 이름만 보고 서류가 다 있는지 검사하자.
이름에 넣을 단어를 공지하고, 못 찾은 서류는 체크리스트로 챙기게 하자」는 안이 나왔다.

ADR-022 는 「증빙 서류를 받는다」를 대안으로 두고 뺐다. 이번 안은 서류를 받지 않으므로 그 대안과 다르다.

## 결정

1. **평가 준비 화면에 네 번째 탭 「서류 점검」을 둔다.** 교사가 폴더를 고르면 파일 이름만 읽는다.
   파일 내용을 읽지 않고 서버로 보내지 않는다.
2. **검사 대상은 교사가 챙기는 검토문서 6종이다.** 보육일지 · 보육계획안 · 영유아 평가 기록 · 부모 개별면담 기록 · 교육 이수증 · 개별화교육계획(해당 반만).
   원장이 챙기는 서류(운영계획 · 연간 보육계획안 · 상호작용 관찰 기록 · 직무교육 이수증)와 평가 당일 서류는 검사하지 않고 체크리스트로만 둔다.
3. **이름에 날짜와 정해진 단어가 있어야 센다.** 날짜는 `2026-10-15` · `20261015` · `2026.10.15` · `2026-10` 을 읽는다.
   - 보육일지 — 지난달 1일부터 어제까지 평일마다. 이름에 「주간」이 있으면 그 주 월~금을 덮는다.
   - 보육계획안 — 지난달 · 이번 달에 1건씩. 「연간」 · 「개별화」가 든 이름은 뺀다.
   - 나머지 — 최근 1년 안에 1건 이상.
4. **결과는 「이름으로 찾음 · 일부 빠짐 · 못 찾음」이다. 「충족」이라 하지 않는다.** 센 파일 이름을 보여 줘 교사가 직접 확인하게 한다.
5. **파일 이름은 어디에도 저장하지 않는다.** 검사 결과는 화면 메모리에만 있다. 새로고침하면 다시 고른다.
6. **못 찾은 서류 · 원장 서류의 체크는 이 브라우저(localStorage)에 항목 id 만 남긴다.** 키는 원 · 학년도다. 파일 이름 · 아동 정보는 넣지 않는다.
7. **이름 규칙은 서류 항목마다 그 줄에 적는다.** 따로 접는 규칙 상자 · 공지 문구 복사는 두지 않는다 — 항목에 이미 보여 중복이다.

## 근거

- **[출처]** 검토문서와 기간은 「2024 개정 어린이집 평가 매뉴얼(2026.2)」 p.169(영역 4) · p.171(영역 5) · p.29(기록 확인 기간)다. 영역 6 · 영역 1~3 은 관찰 · 면담뿐이다(ADR-022 각주 2026-10-28).
  위생 점검표는 검토문서가 아니어서 넣지 않는다.
- **[출처]** 보육일지 · 계획안은 「현장평가월 이전 1개월부터 현장평가 전일까지」를 본다(p.29). 평가월을 모르므로 오늘 평가한다고 보고 지난달 1일 ~ 어제를 쓴다.
- **[판단]** 날짜 없이 단어만 보면 작년 파일 · 빈 양식도 「있음」이 된다. 날짜로 기간 안의 파일만 세고, 일지는 빈 평일을 보여 준다.
- **[판단]** 파일 이름에 아동 실명이 들어갈 수 있다(예: 「김하늘_관찰일지」). 브라우저에 실명을 저장하지 않는다(ADR-013). 항목 id 는 실명이 아니다.
- **[판단]** 체크를 서버에 두면 테이블 · API · 마이그레이션이 필요해 11/11 제출 전에 끝내기 어렵다. 이 체크는 교사 개인의 준비 메모라 기기를 옮기면 다시 체크해도 된다.
- **[판단]** 원장 서류는 교사 폴더에 보통 없다. 검사하면 교사가 손쓸 수 없는 「못 찾음」만 늘어난다.

## 대안

**서류를 서버로 올린다** — ADR-022 에서 뺐다. 올려도 내용 충족은 모른다.

**단어만 보고 날짜는 보지 않는다** — 공지가 짧아지지만 기간 밖 · 빈 양식 파일로 거짓 「있음」이 나온다.

**체크를 저장하지 않는다** — 매번 다시 체크해야 한다.

**체크를 서버(원 단위)에 저장한다** — 자체평가 체크처럼 원 전체가 본다. 일정이 크다. 필요해지면 옮긴다.

**영역 4 · 5 검토문서를 전부 검사한다** — 원장 서류가 교사 화면에 「못 찾음」으로 쌓인다.

## 결과

- 백엔드 · api-spec 변경이 없다. 프런트에만 `lib/workspace/evaluation-files.ts` 와 「서류 점검」 탭이 생긴다.
- 폴더 선택(`webkitdirectory`)은 PC 브라우저에서만 된다. 아이폰 사파리는 폴더를 고르지 못한다.
- 이름으로 찾았다는 것은 내용 · 아동별 횟수(연 2회)를 보장하지 않는다. 화면에 그렇게 적는다.
- 공휴일 · 방학도 빈 평일로 보인다(ADR-022 와 같은 이유로 달력이 없다).
- 쌤플에서 확정한 문서를 내려받아 같은 폴더에 두면 두 탭에서 따로 센다. 두 결과를 합치지 않는다.
- 체크는 기기 · 브라우저마다 따로다. 브라우저 데이터를 지우면 사라진다.
