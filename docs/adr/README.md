# ADR — Architecture Decision Record

「왜 이렇게 정했나」를 결정 하나당 한 파일로 남긴다.

## 왜 쓰나

3주 뒤에 "이거 왜 이렇게 했지?"를 묻는 사람이 우리 자신이다.
코드에는 결과만 남고 대안과 근거는 사라진다. 그러면 같은 논의를 다시 한다.

위클리 보고서·발표 자료의 재료도 된다.

## 형식

```markdown
# ADR-00N: 제목

- 날짜
- 상태 — 채택 | 폐기 | 대체됨(ADR-00M)

## 맥락      무엇이 문제였나
## 결정      무엇으로 정했나
## 근거      왜.  [실측] [출처] [판단] 라벨을 붙인다
## 대안      무엇을 안 골랐나. 왜
## 결과      이 결정이 무엇을 강제하나
```

## 근거 라벨

```
[실측]   우리가 파일·API로 직접 확인
[출처]   법령·정부 문서 인용
[인터뷰] 현장 증언
[판단]   근거 없는 제안.  뒤집어도 되는 것
```

`[판단]`이 붙은 결정은 근거가 없다는 표시다. 실제로 여러 개를 뒤집었다 — ADR-008 참조.
