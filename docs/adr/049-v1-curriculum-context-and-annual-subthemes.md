# ADR-049: v1 생성에 누리과정 맥락과 확정 연간 소주제를 전달한다

- 날짜: 2026-10-30
- 상태: 제안 — 사용자 요청에 따른 로컬 구현·리뷰 대상. PR 전 번호 중복 확인 필요.
- 보충: ADR-041. v2 생성·자료 승인·법정 안전 배치 계약은 변경하지 않는다.

## 맥락

[실측] 연간의 소주제는 `plans.sub_themes`에 저장되지만 월간 생성에는 전달되지 않았다.
연간 생성기도 월·연령·선택된 주제만 받아, 승인된 누리과정 내용을 작성 맥락으로 읽지 않았다.
연간 내보내기는 3열 고정 양식이라 요청한 좌우 배치·월별 주차 칸과 달랐다.

## 결정

1. 승인된 `ssuksak.nuri-curriculum-content / nuri-curriculum-content-v0.1.0`의 59개 내용을
   연간 주제·소주제, 월간, 주간의 `curriculum_context`로 전달한다. 미승인·누락·손상 시
   호출 전에 거절한다. 원본 PDF나 새로운 해설·사례 Reference를 읽지 않는다.
2. 이는 교육적 작성 맥락이다. 59개 ID를 v1의 새 `grounding_refs` 또는 `reference_id`
   허용 목록으로 만들거나, 각 칸의 `CURRICULUM` 근거로 일괄 기록하지 않는다.
   기존 칸별 출처·후보·안전교육 배치 검사는 유지한다. 새로 전달한 내부 ID가 문장에
   출력되면 거절한다.
3. 생성 시 확정 연간의 **대상 월 소주제 현재 값**을 읽어 월간 Core 명령에 전달한다.
   월간 본문의 `parent_subthemes`에 복사해 두어 칸 재생성에서도 같은 부모 맥락을 쓴다.
   없는 옛 본문은 빈 tuple로 읽는다. 소주제를 연간 Core의 기존 item_id로 위장하지 않는다.
   월간의 기존 부모 계획·항목 근거와 확정 게이트는 유지한다. 새 공개 요청 필드는 없다.
4. 새 연간 소주제는 Core `canonical_week_periods`가 계산한 월별 4·5개를 생성하고 검사한다.
   월별 넓은 주제를 익숙한 대상·경험으로 나누며 월간·주간에서 구체화한다. 배열 순서는
   **예상 순서**이며 새 WeekId 배정 상태나 확정 운영 일정을 저장하는 것이 아니다.
   월간에 소주제를 하나씩 주차 칸으로 강제 복사하지 않는다.
5. 연간 제출 문서는 나눔고딕 본문 9pt, 제목 20pt, 머리 10.5pt, 상·하 여백 18mm,
   좌우 6개월, 월·생활주제 병합과 주·소주제 칸으로 출력한다. 모든 달의 실제 주차 수를
   사용하고 두 반년의 주 수가 달라도 격자 누락 없이 채운다. 원래 양식도 보존한다.
   기존 계획에서 소주제가 주차 수보다 많으면 마지막 칸에 남은 내용을 줄별로 함께 싣는다.
   적으면 남은 칸은 비운다. 저장된 계획과 문장은 변경하거나 잘라 버리지 않는다.

## 근거

- [출처] 승인된 누리과정 내용 Catalog와 ADR-042 §4: 내용 ID를 연령별 허용·금지로
  나누지 않는다. 도구·활동의 연령 적합성 및 안전 검사는 유지한다.
- [출처] 2019 개정 누리과정 해설서 PDF 19·37·38·60쪽: 연령 구분 없는 공통 내용.
  지원에 관한 기존 검토 자료(해설서 PDF 49~51쪽, 놀이실행자료 PDF 39~45쪽)는
  작성 원칙을 정리할 때 참고한 자료다. 그 해설·사례 원문을 입력에 옮기지 않는다.
- [판단] 유아의 선택, 확인하지 않은 시설·반응을 사실로 쓰지 않기, 결과물 강제 금지,
  익숙한 대상·경험으로 표현하기는 제품의 자체 작성 지침이다. 국가 공식 분류·월별
  필수 주제·자동 품질 판정 규칙으로 해석하지 않는다.
- [실측] 월간 Context fingerprint와 주간 request fingerprint에 누리과정 내용·판이 포함된다.
  부모 소주제 값이 달라져도 월간 fingerprint가 달라진다.

## 결과와 한계

- 자료 파일·승인 정보·Golden·동결 SHA는 바꾸지 않는다. R1 전체 검토표·생태놀이
  37개·v7·trial2 지침을 런타임 Reference로 활성화하지 않는다.
- 새 조립 경로는 월간 v19 / 안전 v17 / 칸 v11, 주간 v3 / 수리 v2 / 칸 v2를 사용한다.
  입력을 추가하지 않는 기존 Core 경로는 이전 판과 fingerprint를 유지한다.
  연간 요청에는 주제 `annual-theme-text-v2`, 소주제 `annual-subthemes-v2`를 명시한다.
- 연간의 기존 Generation 모델에는 상세 프롬프트·입력 fingerprint 저장 칸이 없다.
  이번 변경으로 연간의 칸 근거가 59개 내용별로 추적된다고 주장하지 않는다.
- `parent_subthemes`는 Core 본문 필드라 DB migration과 공개 응답 필드 추가는 없다.
  이전 코드로 되돌린 뒤 다시 저장하면 이 새 맥락 필드는 사라질 수 있다.
- 기존 주제 후보 12개를 확대하거나 교사가 확정한 기존 계획을 다시 생성하지 않는다.
  새 입력의 실제 문장 품질·비용은 유료 실측 전이며, 한글 실제 쪽 나눔은 별도 렌더 검증 대상이다.
- 월간·주간의 표 구역·폰트·주차 칸을 v2처럼 바꾸는 결정은 포함하지 않는다.

## 대안

- 조사한 모든 PDF를 넣기: 승인·권리·비용 경계를 무너뜨리므로 제외한다.
- 소주제를 연간 Core 항목으로 전면 이관하기: 기존 서버 부가 저장을 유지하는 작은 연결로 해결한다.
- 기존 계획을 주차 수에 맞게 잘라 저장하기: 교사 값을 잃으므로 출력에서 전부 보존한다.
