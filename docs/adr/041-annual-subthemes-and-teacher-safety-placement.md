# ADR-041: 연간 소주제 생성과 교사 안전교육 배치 입력

- 날짜: 2026-10-21
- 상태: 채택 — 사용자의 연간 내용 보완 구현 요청. 법령·참고자료 승인 내용은 변경하지 않음.

## 맥락

[실측] 주제만 생성하고 소주제는 비워 둔다. 안전교육 배치 입력도 없어 확정 파일의 두 열이 빈다.
[출처] ADR-014와 승인된 안전교육 규칙은 기관·교사 입력 없는 월 배치 창작을 금지한다.

## 결정

- 소주제는 선택된 주제·반 연령에서 12개월을 한 번에 생성한다. 기존 주제 생성 뒤 두 번째 문서 단위 호출이며 월별 호출은 없다.
- 기존 Core 주제 포트는 유지한다. 생성 후 commit 전 서버가 소주제를 검증·저장하고 실패하면 전체 transaction을 폐기한다.
- 안전교육은 교사 직접 입력만 받는다. 미입력(null)·배치 없음([])·배치 있음(6종 id)을 구분한다.
- `plans.annual_safety` JSONB 한 칸에 월별 배치와 변경 이력(before/after, user id, UTC 시각)을 보관한다.
- 생략한 선택 필드는 기존 값을 보존한다. 확정본 읽기 전용과 원 격리, 행 잠금을 유지한다.
- 화면과 HWPX의 이름은 승인된 규칙 파일의 공식 label을 쓴다. 시간 입력 없이 법정 시수 충족을 주장하지 않는다.

## 근거

[판단] 별도 소주제 생성 한 번은 주제 Core·Golden 변경 없이 기존 저장 경로를 살리는 작은 확장이다.
[판단] 교육 배치는 12개월의 작은 문서 상태라 별도 관계형 테이블보다 한 JSONB가 단순하다.

## 대안

- Core 포트·도메인에 소주제를 넣기: 기존 계약과 Golden까지 바뀐다. 현재 서버에 독립 저장 칸이 있어 보류한다.
- AI가 안전교육 일정을 채우기: 승인된 규칙의 배치 출처 제한에 어긋나므로 하지 않는다.

## 결과

기존 확정본을 바꾸거나 확정을 취소하지 않는다. 기존 초안의 소주제는 직접 수정할 수 있다.
새 생성에서 소주제까지 만든다. 교육 주기 검사와 시수 미검증 안내를 구분하고 화면·DB·파일 경로를 테스트한다.
