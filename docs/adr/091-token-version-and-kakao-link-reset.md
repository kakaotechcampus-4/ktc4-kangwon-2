# ADR-091: 토큰에 계정 버전을 싣고, 카카오를 이으면 먼저 있던 비밀번호를 끊는다

- 날짜: 2026-11-10
- 상태: 제안
- 관련: ADR-069(카카오 로그인 · 같은 이메일 계정에 잇기) · `docs/api-spec.md` §0 · §0-1

## 맥락

[실측] 이메일 가입(`POST /api/auth/signup`)은 그 메일의 주인인지 확인하지 않는다. 남의 이메일로 먼저 가입할 수 있다.

[실측] 카카오 로그인은 카카오가 검증한 이메일이 같은 계정을 찾으면 그 계정에 `kakao_id` 만 붙이고 비밀번호는 그대로 뒀다(ADR-069 결정 4).
그래서 남의 이메일로 먼저 가입해 둔 사람은 진짜 주인이 카카오로 들어온 뒤에도 자기가 만든 비밀번호로 계속 들어온다.
주인이 그 계정에 적는 원 · 반 · 아동 명단 · 관찰 기록을 같이 본다. ADR-069 는 이 동작을 정하지 않았다 — 비밀번호를 「두지 말자」고도 「두자」고도 쓰지 않았고,
`test_같은_이메일로_가입한_계정에_잇는다` 가 「비밀번호 로그인도 그대로 된다」를 확인했을 뿐이다.

[실측] 토큰은 `{sub, exp}` 뿐이고 서버가 끊을 길이 없었다(`shared/auth/tokens.py` 머리말). 비밀번호를 바꿔도, 위처럼 비밀번호를 끊어도
이미 나간 토큰은 12시간 동안 통과한다. 비밀번호만 막으면 들어와 있던 사람은 남는다.

## 결정

1. **`users.token_version`(정수, 기본 0)을 둔다.** 토큰 본문에 `ver` 로 싣고, 요청마다 `current_user` 가 계정의 값과 같은지 본다. 다르면 401 이다.
   토큰마다 저장소를 두지 않는다 — 계정 하나에 숫자 하나로 「그 전 것 전부」를 끊는다.
2. **비밀번호를 바꾸면 버전을 올리고 새 토큰을 준다.** `PATCH /api/auth/password` 는 204 대신 200 과 로그인과 같은 응답(`token` · `user`)이다.
   바꾼 브라우저는 그 토큰으로 이어 가고, 다른 기기 · 다른 사람의 토큰은 끊긴다.
3. **카카오로 「이메일로 먼저 가입한 계정」에 이을 때, 그 비밀번호를 아무도 모르는 값으로 바꾸고 버전을 올린다.**
   카카오로만 만든 계정과 같은 방식이다(ADR-069 결정 7). 이은 뒤에는 카카오로만 들어온다. 이미 이어진 계정이 다시 카카오로 들어올 때는 바꾸지 않는다.
4. **`ver` 가 없는 옛 토큰은 0 으로 읽는다.** 열 기본값도 0 이라, 배포 순간 로그인해 있던 교사가 튕기지 않는다. 이 판 직전 코드도 새 열을 모른 채 돈다(ADR-073).

## 근거

- [판단] 서버는 어느 쪽이 먼저 가입한 「진짜」 사람인지 모른다. 확인된 쪽은 카카오(검증된 이메일)뿐이라 그쪽만 남긴다.
- [판단] 비밀번호만 끊고 토큰을 두면 들어와 있던 사람이 12시간 머문다. 둘은 같이 고쳐야 효과가 있다.
- [판단] 이메일 인증 메일을 붙이는 것이 뿌리를 막는 길이지만 메일 발송 의존을 새로 들여야 한다. 제출 전에 넣을 수 있는 크기가 아니다.

## 고르지 않은 대안

- **이메일 가입에 인증 메일을 붙인다** — 뿌리를 막는다. 메일 발송 서비스 · 대기 상태 · 재발송 화면이 같이 들어온다. 발표 뒤 다시 본다.
- **같은 이메일이면 잇지 않고 409** — ADR-069 가 버린 안이다. 이메일로 가입한 교사가 카카오를 못 쓴다.
- **토큰을 DB 에 저장하고 지운다** — 요청마다 조회가 늘고, 끊을 단위가 「계정 전체」면 숫자 하나로 충분하다.
- **비밀번호 변경은 204 를 두고 화면이 다시 로그인한다** — 새 비밀번호를 화면이 들고 있다가 한 번 더 보내야 한다. 응답에 새 토큰을 싣는 쪽이 단순하다.

## 결과

- 이메일로 가입한 교사가 카카오를 한 번 누르면 그 뒤로 이메일 · 비밀번호로는 못 들어온다. 「비밀번호 바꾸기」도 지금 비밀번호를 몰라 쓸 수 없다(카카오로만 만든 계정과 같다).
- 이 변경 전에 이미 이어진 계정의 비밀번호는 그대로 남는다. 운영 DB 에서 `kakao_id` 가 있고 이메일로 먼저 가입한 계정은 사람이 확인한다.
- 비밀번호를 바꾸면 그 교사의 다른 기기도 로그인 화면으로 간다.
