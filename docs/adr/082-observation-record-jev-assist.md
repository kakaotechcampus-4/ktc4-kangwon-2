# ADR-082: 관찰 기록을 적을 때 jev 가 영역을 제안하고 빠진 것을 짚는다 — 정하지도 쓰지도 않는다

- 날짜: 2026-11-10
- 상태: 제안 (관찰 기록 화면 · 서버. PM 딸깍 시안 3판 「점검으로 바뀐 것」)

## 맥락

[실측] 관찰 기록 화면은 영역 칩 중 첫 영역(신체운동·건강)이 눌린 채 시작했다. 안 바꾸면 그대로 저장돼
블록 놀이 기록이 관찰일지 종이의 신체 줄에 들어갔다(`RecordsPage.tsx` 의 `picked || domains[0]`).

[실측] 교사가 빠뜨리기 쉬운 것은 「아이 반응」이다. 화면에는 「상황 → 행동 → 반응 → 교사 지원」 안내 글만 있고,
재료가 모자란 기록으로 만든 관찰일지는 해석 · 지원을 쓸 근거가 없다.

관찰 기록은 **사실기록형**이다(CLAUDE.md 문서 5분류). 모델이 값을 정하거나 글을 쓰면 위조다.

## 결정

1. **영역 기본값을 없앤다.** 아무것도 안 눌린 채 시작하고, 안 고르면 저장하지 않는다.
2. **영역 추천은 제안만 한다** — `POST /api/observations/domain-suggest {class_id, fact, context}` → `{domain|null, confidence}`.
   - 판정 전용 모델 jev(ADR-071, `shared/llm.decide`)에 5영역 고르기 하나를 묻는다. 보기 설명은 누리과정 전사본의 내용범주 · 내용이다.
   - 1순위 확률이 **0.8 이상**일 때만 `domain` 을 준다. 화면은 그 칩에 보라 점선을 치고, **교사가 한 번 눌러야** 들어간다.
   - mock · 2축 원(`DAILY_PLAY_2`) · 가명 실패 · jev 실패면 묻지 않거나 둘 다 null 이다. 기록은 막지 않는다.
3. **저장 뒤 빠진 것 쪽지** — `POST /api/observations/{id}/missing` → `{missing: ["상황" | "행동" | "반응"]}`.
   - 셋을 예 · 아니오로 묻고, 「없다」 확률이 0.6 이상인 것만 돌려준다. 상황 칸을 적었으면 상황은 묻지 않는다.
   - 화면은 첫 번째 하나만 쪽지 한 줄로 띄운다(「아이 반응이 안 보여요. 한 줄 더 쓸까요?」). **글을 쓰지 않고 저장을 막지 않는다.**
   - mock · 실패면 빈 목록이다.
4. **두 길 모두 원 전체 아이 이름을 가명으로 바꾼 뒤 부른다** — 일지 AI 검토와 같은 표(`documents/verify._name_table`).
   못 바꾸면 부르지 않는다.
5. 결과는 저장하지 않는다. 글은 로그에 찍지 않고, 비운 까닭(예외 종류)만 남긴다.

## 근거

- [실측] 2026-11-10, 지어낸 관찰 56문장 × 2회(`jev-1.14`): 맞힘 95%, 두 번 같은 답 100%, 평균 0.57초, 한 번 약 ₩0.1.
  1순위 확률 0.8 이상만 고르면 추천 비율 79%, 그때 맞힘 96%. 0.6 이면 95% · 94%.
  틀린 쪽은 의사소통 → 사회관계 · 자연탐구, 예술경험 → 자연탐구였다(경계 문장).
- [판단] **0.8.** 「그대로 두면 그 영역」은 AI 가 조용히 정하는 것과 같아서 뺐고, 제안이 틀리면 교사가 그대로 누를 수 있다.
  추천을 조금 덜 띄우고(79%) 틀린 제안을 줄이는 쪽을 골랐다.
- [판단] **2축 원은 끈다.** 2축 보기로는 재지 않았다. 따로 재기 전까지 제안하지 않는다.
- [판단] **빠진 것 0.6 은 재지 않은 값이다.** 3단 게이트의 `P_FLAG` 와 같은 값에서 시작했다. 너무 자주 뜨면 교사가 쪽지를
  무시하게 되니 파일럿 기록으로 다시 잰다.
- [판단] 추천 질문에 상황 칸을 「(상황: …)」으로 붙인다. 실측 문장에는 상황 칸이 없었다 — 바꾸면 다시 잴 자리다.

## 대안

- **그대로 저장하면 제안한 영역** — 실측 기준 약 3%가 틀린 채 저장된다. 교사가 고르지 않은 값이 종이 줄을 정한다.
- **생성 모델(gpt)로 고르기** — 글을 쓰는 모델이라 답 모양이 흔들리고 값도 더 든다. jev 는 보기 · 확률로만 답한다.
- **빠진 것을 저장 전에 막기** — 교사가 바쁜 시간에 적는 칸이다. 막으면 기록 자체를 안 남긴다.

## 결과

- 관찰 기록 화면의 영역은 교사가 고른 값만 저장된다.
- api-spec §10 에 두 엔드포인트가 더해진다. 둘 다 덤이라 실패해도 200 이다.
