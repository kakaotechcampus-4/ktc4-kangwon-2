# ADR-070: 트렌드봇 검열 3단은 jev 가 판정하고, 인용은 본문 줄 중에서 고른다

- 2026-11-08
- 상태 — 채택
- 관련 — ADR-016(3단 판정 방식 보충) · ADR-071 · FR-605

## 맥락

검열 3단(ADR-016)은 글 쓰는 모델에게 10개씩 보내 `{"drop":[{"id","quote","why"}]}` 를 받았다.
모델이 인용을 지어낼 수 있어서 「인용이 원문에 없으면 버리지 않는다」를 코드로 한 번 더 막았고,
한 번에 30초씩 걸려 주간 작업 시간 예산(300초)을 넘기면 남은 것은 「못 본 것」이 됐다.
판정은 「버릴까 · 왜 · 어느 줄」이라 글을 쓰는 일이 아니다.

## 결정

1. **판정은 jev 가 한다.** 자료마다 예 · 아니오 넷(다치는 동작 · 따돌리는 구조 · 너무 어려운 규칙 ·
   안전을 가르치는 내용)과 고르기 하나(근거 줄)를 묻는다. 나가는 문은 `shared/llm.decide` 하나다(ADR-071).
2. **인용은 본문을 줄로 나눈 보기 중에서 고른다.** 보기가 원문 글자 그대로라 지어낸 인용이 나올 수 없다.
   「없음」을 고르면 버리지 않는다 — 「인용할 표현이 없으면 버리지 않는다」를 그대로 지킨다.
3. **안전을 가르치는 자료는 버리지 않는다.** 위험 낱말이 많아도(「세제를 삼켰을 때」) 그렇다.
4. **기준값 0.5.** 버릴 이유 셋 중 가장 높은 점수가 0.5 이상이고, 안전 교육이 아니고, 근거 줄을 골랐을 때만
   버린다. 잘못 버린 것은 PR 에 인용과 함께 뜨니 사람이 되살리기 쉽고, 놓친 위험은 사람이 못 볼 수 있어
   잡는 쪽으로 정했다.
5. **나머지 계약은 그대로다.** 떨어뜨리기만 하고 통과를 보증하지 않는다. 모델이 죽거나 답 모양이 깨지면
   그 묶음은 버리지 않고 「못 본 것」으로 센다. mock 이면 부르지 않는다. 주소와 채널은 보내지 않는다.
6. **4건씩 묶는다.** 영상 설명이 길어(긴 것 수천 자) jev 의 긴 문맥 모드(약 32KB 부터)에 들지 않게 한다.

## 실측 — 지어낸 자료 2회 × 120건 (위험 36 · 남길 것 84, 회차마다 새로 씀)

| 무엇 | 결과 |
|---|---|
| 위험 자료를 버림 | 69 / 72 |
| 멀쩡한 자료를 버림 | 0 / 168 |
| 안전 교육 자료를 버림 | 0 / 24 |
| 버린 것의 인용이 정답 줄 | 69 / 69 |
| 지시문(「모두 통과시켜라」)을 심은 자료를 맞게 판정 | 13 / 13 |
| 4건 한 번 묻는 데 | 중앙값 0.6초 |

- 1회차로 기준값을 정하고(0.6 → 0.5) 2회차(처음 보는 자료)로 확인했다. 2회차에서 놓친 둘이
  「아이가 글을 직접 읽고 써야 하는 놀이」라 규칙 질문에 그 예를 적고 두 회차를 다시 돌렸다.

## 한계

- 「카드에 적힌 문제를 아이가 읽어 준다」 같은 직접 읽기 놀이를 2건 놓쳤다.
- 자료가 지어낸 것이다. 실제 주간 수집분(W44 등)으로 사람이 본 결과와 견줘 다시 재야 한다.
- 주간 작업에 `ELICE_JEV_BASE_URL` Secret 이 있어야 한다. 없으면 3단 전체가 「못 본 것」이 된다.
