# ADR-062: 주제형 월간의 행사 일정 · 특성화 · 특별활동 표는 교사가 쓰고 나눈다

- 2026-11-05
- 상태 — 채택 (Human Decision 2026-11-05(하민) — 「행사 일정 편집 안 됨.」 · 「특성화 시간표도, 특별 활동도 셀 나눌 수 있게 하고 편집할 수 있게. 행사도 마찬가지.」 → 「해줘」)
- 관련 — ADR-047(놀이 월간 특별활동 시간표 칸 나누기) · ADR-055(확정본 read-only) · template-a-validation(`event_schedule` · `special_program` 비활성) · api-spec §9-1 · §9-3

## 맥락

주제형 월간(v1) 화면과 한글 양식에는 행사 일정 · 특성화 시간표 · 특별활동 시간표 칸이 있으나 빈 정적 칸이었다.
교사가 쓸 수도, 놀이 월간처럼 나눌 수도 없었다.

## 결정

1. **세 표는 교사가 쓰는 문서 단위 표다.** Template A Section 이 아니다 — `event_schedule` · `special_program` 은
   Template A 에서 계속 비활성이고, 생성 · 검증 · 재생성 대상이 아니다. 계획안의 `teacher_tables` 로 따로 둔다.
2. **AI 는 채우지 않는다.** 처음엔 빈 칸이고, 교사가 쓰면 생성 방식 `MANUAL` · `TEACHER_EDITED` 이력이다.
   Evidence 는 없다. LLM 이 행사 · 시간표를 지어내지 않는다.
3. **나누기 · 빼기 · 크기는 ADR-047 놀이 월간 시간표와 같은 모델 · 같은 API 모양이다** — 위아래 · 좌우 나누기,
   깊이 4, 비율 10~90, 칸 폭 3.5% 이상, 열 폭 5% 이상. 표 높이만 v1 양식에 맞춰 10~80mm 다. 경로는 `/plans/monthly/{id}/...`.
   변경마다 계획안 단위 `TIMETABLE_CHANGED`(`table_key` 포함) 이벤트를 남긴다.
4. **안정 주소.** 칸 id 는 `{plan_id}.{table}.{열}.{n}` 로 결정적이고 나눠도 원래 칸 id 를 유지한다.
   표를 저장하기 전 계획안도 같은 빈 표를 같은 id 로 받으므로 마이그레이션이 없다. `label` 은 양식 이름(source_label)이고 `table_key` 와 분리한다.
5. **확정본은 막는다** — 쓰기 · 나누기 · 빼기 · 크기 모두 409 `ALREADY_CONFIRMED`.
6. **한글 내려받기는 나눈 모양 · 열 폭 · 높이 그대로 양식 칸을 다시 그린다.**

## 근거

- 행사 · 시간표는 기관마다 다르고 Reference 에 없다 — Rule 이 정할 근거가 없으므로 교사 입력만 받는다(CLAUDE.md §5 · §13.2).
- ADR-047 의 순수 함수 · 한도를 그대로 쓰면 두 화면의 칸 나누기가 같은 감각이고 새 규칙이 늘지 않는다.

## 남은 것

- 표 칸의 칸 단위 이력은 §9-5 이력 목록에 아직 나오지 않는다.
- 화면은 끌기 대신 ± 단추로 칸 비율 · 표 높이만 바꾼다. 열 폭은 API 만 있다.
