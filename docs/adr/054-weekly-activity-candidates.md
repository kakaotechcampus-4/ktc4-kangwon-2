# ADR-054: 주간 대소집단 활동 후보와 교사 배치·분할

- 일자: 2026-11-01
- 상태: 사용자 방향·후보 선정 정책 확정, 로컬 구현·교차 리뷰 보완 중
- 보완: ADR-051의 대소집단 DAY 구역, ADR-053의 주간 작성 맥락

활동 종류 표시는 공백을 통일한다. 기존 활동 종류 목록에서 확인된 원문 태그/행 이름만 사용하며, 재료·행사 메모를 유형으로 출력하지 않는다. 확인되지 않으면 `기타`로 표시한다. 이 정리는 원 근거와 승인 분류를 바꾸지 않는다. 나눈 칸의 DELETE는 기존 놀이 월간 선례처럼 1 이상 정수인 `expected_revision` 쿼리를 받는다.

교사가 한 주에 할 활동을 선택할 수 있게 활동 유형이 표시된 후보를 약 10개 만든다. 후보를 같은 주 소주제와 일치시키려고 바꾸지 않는다. 월·연령·승인 분류·기관 상한은 유지하며 명시된 자료 유형을 보존해 유형별로 먼저 하나씩 고른 뒤 남는 자리를 채운다. 근거가 모자라면 개수를 채우려고 만들지 않는다. 종류는 원문 태그/행 이름에서 확인된 표현이고 새 국가 분류 체계가 아니다.

월간 주제는 후보 검색 순위에 반영하되 주간 소주제와의 일치는 강제하지 않는다. 주별 회전·중복 배제는 보류하므로 같은 달의 주들이 같은 후보 근거를 받을 수 있다.

LLM은 Rule이 정한 후보별 근거 안에서 `활동명: 설명`을 쓴다. 후보의 유형과 근거 ID, 요일 배치는 LLM이 바꾸지 않는다. 초기 요일 칸은 비운다. 교사는 후보를 칸으로 복사하거나 직접 고친다. 복사할 때는 `[유형] 활동명`만 넣고 설명은 후보 패널에서 읽는다. 복사는 CANDIDATE_COPIED와 원 후보 ID를 기록하고 후보 수정이 이미 복사한 값을 자동으로 바꾸지 않는다.

새 생성 요청의 `activity_candidates: true`로 이 방식을 명시한다. 서버는 승인된 v0.2.0 양식을 사용한다. 기존 요청/저장 계획/전역 양식 기본값은 바꾸지 않는다. 후보형 계획에는 `activity_candidates`, 요일 순 `activity_grids`를 저장한다. 각 격자 leaf는 실제 WeeklyCell의 item_id를 가리키며 값은 cells에 한 번만 저장한다. 후보·삭제한 칸도 근거와 이력을 보존한다.

한 요일 칸을 위/아래 또는 왼쪽/오른쪽으로 나눈다. 첫 칸의 ID와 값은 유지하고 새 빈칸만 추가한다. 월간 v2와 같은 분할 트리 연산, 깊이 4·비율 10~90·최종 폭 3.5% 하한을 적용한다. 삭제한 칸은 보관하고 마지막 칸은 지우지 않는다. 확정본은 변경하지 않는다. 다른 주간 항목과 특별활동은 기존 역할을 유지한다.

서버는 소유권·revision·확정 게이트와 기존 오류 코드를 재사용한다. 후보 복사/칸 분할·삭제는 기존 칸 주소 아래 새 경로로 제공한다. 상세 응답은 후보 목록과 격자 트리를 추가하며 구판에서는 빈 목록이다. 변경 이력은 후보와 삭제한 칸도 포함한다. HWPX에는 선택해 놓은 칸만 내보내고 후보 목록은 싣지 않는다. 분할한 출력은 월간 v2의 분수 좌표 정수화 원칙을 따른다.

후보 생성과 수리는 내부 스트리밍·출력 상한 6,000토큰을 쓰고 최대 수리 1회는 유지한다. 전송의 전체 마감 120초·소켓 대기 30초를 유지하며 nginx의 주간 생성 경로만 270초로 둔다. 후보가 없는 기존 주간 호출·칸 재생성은 기존 전송 그대로다.

서버·화면·내보내기를 함께 배포해야 한다. 여러 leaf를 저장한 본문은 이 계약을 모르는 구버전에서 읽을 수 있다고 보장하지 않는다. 실제 LLM 문장 품질·내용을 채운 한글 렌더와 운영 연결 성공은 구현 단위 검사와 별도로 확인한다. 이 결정은 자료·Template 승인이나 운영 모델·유료 호출 승인이 아니다.

## 실내 자유놀이 후보 확장 (2026-11-03, 사용자 요청에 따른 로컬 구현·교차 리뷰 대상)

새 생성 요청의 `indoor_play_candidates: true`는 기존 후보 방식과 승인된 요일 양식을 함께 사용한다. 실내놀이도 승인된 실내놀이 근거에서 영역별로 약 10개 후보를 만들되 부족한 자료로 개수를 억지로 채우지 않는다. 월·연령·승인 분류·기관 상한과 부모 월간의 작성 맥락을 유지한다. 원문 영역을 확인할 수 없으면 `기타`이며 새 분류를 추측하지 않는다.

후보 목록은 기존 `activity_candidates`에 보존하고 `section_key`로 실내놀이/대소집단을 구분한다. 문서에는 처음 빈 실내놀이 항목 하나가 있고, 교사가 후보를 고르면 `[영역] - 활동명`을 별도 실제 칸으로 복사한다. 설명은 후보 패널에서 읽는다. 여러 항목은 `indoor_play` Section의 순서 있는 cells로 저장하며 요일은 모두 null이다. NONE은 주 전체라는 시간 단위를 그대로 뜻한다. 주 전체의 넓은 HWPX 칸에는 선택한 항목만 문단별로 합쳐 출력한다.

교사는 각 항목을 편집·추가·빼기·순서 변경할 수 있다. 후보 수정이 문서의 복사본을 자동으로 바꾸지 않으며 복사는 원 후보 ID·근거·이력을 남긴다. 이미 넣은 같은 후보는 중복 추가하지 않는다. 마지막 항목을 빼면 새 빈 항목을 남기고 지운 칸은 이력용으로 보관한다. 새 요청을 하지 않은 기존 계획을 자동 전환하지 않는다.

이 확장은 공개 필드·경로를 포함하므로 서버·화면을 함께 배포한다. 로컬 계약/구현의 교차 리뷰가 끝나기 전에는 운영 지원 완료로 표시하지 않는다.
