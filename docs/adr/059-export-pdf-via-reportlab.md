# ADR-059: PDF 는 내보낸 hwpx 의 표를 reportlab 으로 다시 그려 만든다

- 2026-11-03
- 상태 — 채택 (2026-11-03 하민 — 새 의존성 `reportlab` · 서버 이미지 `fonts-nanum` · 일지 PDF 내려받기 포함)
- 관련 — ADR-021(「PDF — 대비책으로만 둔다」 보충) · ADR-039(hwpx 한 벌에서 변환) · ADR-004(아동 실명) · api-spec §9 · §11

## 맥락

ADR-021 은 내보내기를 hwpx 로 하고 PDF 는 「대비책으로만」 두었다. ADR-039 가 `.hwp` 를 같은 hwpx 에서
변환하기로 했다. 11/03 PM(하민)이 확정한 계획안에 PDF · HWPX · HWP 내려받기 버튼을 두자고 했다 —
수정할 일이 없는 제출 · 인쇄 · 공유에는 PDF 가 한글 없이 열린다.

## 결정

1. **PDF 는 우리가 만든 hwpx 에서 만든다.** `fill_table` · `fill_grid` 가 채운 hwpx 를 `shared/hwpx_pdf.py` 가
   읽어 reportlab 으로 다시 그린다. 계획안 종류마다 따로 그리지 않는다 — 칸 주소 · 병합 · 너비 · 높이 · 테두리 ·
   바탕색 · 글자 크기 · 굵기 · 색 · 정렬 · 한글 줄 나눔(`breakNonLatinWord`)을 양식이 적어둔 값으로 옮긴다.
   그래서 연간 · 월간 · 주간 · 놀이 프로젝트형 · 일지가 한 길로 나온다.
2. **쿼리 `?format=pdf` 를 더한다.** 경로와 기본(hwpx)은 그대로다. `Content-Type` 은 `application/pdf` 다.
   변환은 ADR-039 와 같은 `shared/hwpx.py` `download()` 한 곳에서 한다.
3. **문서 한 쪽이 PDF 한 장이다.** 쪽은 최상위 문단의 `pageBreak="1"` 로 나눈다. 넘치는 쪽은 한 장에 맞춰 줄인다.
4. **글꼴은 나눔고딕 하나다.** 서버 이미지에 `fonts-nanum` 을 깐다. 로컬 Windows 는 맑은 고딕을 쓴다.
5. **실패하면 503 `DEPENDENCY_UNAVAILABLE` 로 「hwpx 로 받아주세요」를 준다.** 글꼴이 없을 때도 같다.
   reportlab 은 PDF 를 고를 때만 불러오므로, 깨져도 서버 기동과 hwpx · hwp 는 산다(ADR-039 결정 3 과 같은 이유).

ADR-021 · ADR-039 의 나머지(확정본만 · 출처를 싣지 않음 · 작성자 정보를 지움 · 변환은 서버 안에서만)는 그대로다.

## 근거

- **[실측]** `backend/app/features/plans/templates/` 의 양식 10개를 채워 PDF 로 그려 눈으로 보니 표 모양이 양식과 맞았다
  (한글에서 연 화면과 나란히 대조하지는 않았다).
  연간 테스트는 PDF 글자층에서 12개월의 주제 · 소주제를 다 찾는다.
- **[실측]** 칸에 60줄을 넣어도 한 장에 들어가고 글자층에서 모든 줄을 찾는다(줄여서 맞춤).
- **[판단]** hwpx 한 벌에서 만들면 채우는 코드가 늘지 않는다. 양식을 바꾸면 PDF 도 같이 바뀐다.
- **[판단]** 남의 서버로 보내지 않는다. reportlab 은 프로세스 안에서 그린다 — 일지에는 아동 실명이 들어간다(ADR-004).

## 대안

- **LibreOffice(headless)** — hwpx 를 제대로 읽지 못하고, 서버 이미지가 크게 는다.
- **HTML → PDF(WeasyPrint · headless Chromium)** — 시스템 라이브러리나 브라우저가 이미지에 붙고,
  양식마다 HTML 템플릿을 따로 둬야 한다. 채우는 코드가 두 벌이 된다.
- **브라우저 인쇄(화면에서 PDF 로 저장)** — 한 번에 파일이 받아지지 않고 화면 모양이 제출 양식과 다르다.

## 결과

- 교사는 확정한 계획안 · 일지를 PDF 로도 받을 수 있다. 화면은 요청 끝에 `?format=pdf` 를 붙이면 된다.
- **한글에서 연 모양과 똑같지 않다.** 글꼴이 하나이고 줄 간격은 근사다. 글이 많은 쪽은 줄여서 맞추므로
  글자가 작아진다. 칸 안에 든 표(중첩 표)는 그리지 않는다. 수정할 파일은 hwpx · hwp 로 받는다.
- **양식을 바꾸면 PDF 도 한 번 열어 본다.** 자동 테스트는 PDF 글자층에 값이 있는지까지만 본다.
- 서버 이미지에 `fonts-nanum` 이 붙는다. CI pytest 도 같은 글꼴을 깐다.
