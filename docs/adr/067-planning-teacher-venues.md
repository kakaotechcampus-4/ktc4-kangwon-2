# ADR-067: 계획안의 특정 장소는 교사의 명시 입력으로만 허용한다

- 날짜: 2026-11-07 (2026-11-06 사용자 결정을 옮김)
- 상태: 채택 — 검토된 장소명만 차단하고, 교사가 직접 입력·수정한 확정 부모 값을 허용

## 맥락

다른 기관 자료의 장소가 생성 계획안에 그대로 들어오면 우리 반의 실제 방문 예정처럼
읽힌다. 반대로 시설명 접미사로 추정하면 「꼬마미술관」 같은 놀이도 차단한다.
교사가 장소를 직접 입력한 경우와 AI 문장을 단순 확정한 경우도 구별해야 한다.

## 결정

1. `venue_policy.REVIEWED_VENUES`에 검토된 실제 이름만 둔다. 띄어쓰기 차이는 무시하되
   시설 종류·창작 놀이 이름에서 장소를 추정하지 않는다. 새 장소명은 검토 후 추가한다.
2. 생성의 장소 허용 출처는 긍정적인 현재 요청, 직접 입력한 값, 교사가 실제로 문장을
   바꾼 확정 부모의 현재 값이다. 근거 원문, AI 값의 확정, 값이 같은 저장·순서 변경,
   거절된 응답은 허용 출처가 아니다. 제외·방문 금지 요청이 허용보다 우선한다.
   교사가 문장을 실제로 바꾸면 그 값에 남은 장소는 새로 넣지 않았어도 허용한다
   — 2026-11-07 사용자 결정으로 범위를 그대로 둔다.
3. 값의 교사 수정은 기존 Audit을 읽는다. Audit이 없는 연간 소주제 sidecar는 새로
   쓰거나 바꾼 문자열만 `YearlyPlan.teacher_subthemes`에 월별로 보존한다. 연간에서
   전달한 장소는 `MonthlyPlan.parent_teacher_venues`에 남겨 칸 재생성·주간 생성에 쓴다.
   기존 JSON 저장기를 사용하며 두 필드의 기본값은 빈 tuple이다. 옛 소주제의 작성자는
   추정하지 않는다. 직접 입력·파일 가져오기 연간은 교사가 제공한 문서로 취급한다.
4. 맥락형 월간·주간 검색은 검토된 장소명 또는 명시적 현장체험학습·현장학습·현장체험·견학
   표시가 있는 근거를 순위·개수 제한 전에 제외한다. 원문에서 장소만 지우지 않는다.
   이름 없는 일반 지역사회 방문(예: 시장 구매 · 보건소 방문)은 근거에서 빼지 않는다
   — 2026-11-07 사용자 결정.
5. 수리는 기존 한도 안에서만 한다. 문제가 된 장소명만 삭제하거나 시설 종류로 바꾸는
   수리는 거절한다. 수리가 없는 연간 경로에 호출을 추가하지 않는다.
6. 현재 맥락형 경로는 `+teacher-venues-v2`로 구별한다. 비맥락 구판 요청에 표시 없이
   새 검증을 적용하지 않는다. 공개 응답·요청 필드와 DB 테이블은 추가하지 않는다.

## 근거

- [판단] 새 이름을 놓칠 수 있어도, 일반 놀이를 장소로 추정해 막지 않는 사용자 선택이다.
- [실측] 긍정·거절 요청, 무변경 저장, 부모 출처 전달, 이름만 지운 수리 거절은
  `p0-planning/tests/planner/test_venue_policy.py`로 확인한다.
- [실측] 소주제 출처의 JSON 호환성과 실제 DB 저장·재조회는
  `backend/tests/test_annual_content.py`, `backend/tests/test_plans_api.py`로 확인한다.

## 대안

- 시설명 접미사로 자동 추정: 일반 놀이 오탐 때문에 선택하지 않았다.
- 확정된 부모의 모든 장소 허용: 교사가 바꾸지 않은 AI 장소까지 허용하므로 선택하지 않았다.
- 거절된 장소명을 지워 활동으로 재사용: 다른 적격 근거를 고른 것이 아니므로 허용하지 않는다.

## 결과와 한계

목록에 없는 새 장소명, 별칭·오탈자는 통과할 수 있다. 메모의 부정 표현 처리는 제한된
문자열 규칙이며, 모호한 부정 목록은 보수적으로 허용하지 않는다. 이름만 지운 수리의
문자 비교는 모든 의미 변형을 잡는 검사가 아니다. 장소를 허용해도 이용 가능성·예약·일정은
확정하지 않는다. 기존 계획안·교사 편집값·승인 근거·Template·Golden은 일괄 변환하지 않는다.
