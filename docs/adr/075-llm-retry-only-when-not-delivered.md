# ADR-075: 모델에 닿지 못한 LLM 요청만 한 번 더 보낸다

- 2026-11-09
- 상태 — 채택 (하민 결정 2026-11-09). 미확정사항 U-13 을 닫는다.
- 관련 — ADR-036(오류 3종 · 사용량 기록) · ADR-033(수리 1회) · ADR-071(jev)

## 맥락

지금까지 `backend/app/shared/llm/client.py` 는 실패한 호출을 다시 보내지 않았다(`docs/evaluation/05` 「자동 재시도 없음」).
이유는 둘이었다 — 같은 비용이 두 번 나갈 수 있고, 교사는 기다리는 줄 모른다.

그런데 실패 가운데 **요청이 모델에 닿지도 못한 것**이 있다.

- 연결 거부 · 주소 조회 실패 — 요청이 나가지 않았다.
- 게이트웨이 502 · 503 · 504 — 게이트웨이가 모델에 넘기지 못했다.

이 경우는 모델이 돌지 않았으므로 다시 보내도 비용이 두 번 나가지 않는다. 지금은 이런 순간적인 끊김에도 교사가 「다시 시도」를 눌러야 했고,
놀이 연간처럼 구간을 여러 번 부르는 생성은 한 구간이 끊기면 앞서 만든 구간까지 모두 버렸다.

CLAUDE.md §16 은 retry 를 LLM Wrapper 가 맡을 일로 적어 두었고, §21 은 retry 횟수를 기록하라고 한다.

## 결정

1. **모델에 닿지 못한 요청만 1.5초 뒤 한 번 더 보낸다.** 두 번째도 실패하면 지금처럼 `GENERATION_FAILED` 500 이다.
   ```
   다시 보낸다        연결 거부 · 주소 조회 실패 · 502 · 503 · 504
   다시 보내지 않는다  401 · 403 · 429   한도 · 키 — 다시 눌러도 같다 (LLM_BUDGET_EXCEEDED)
                     500 · 그 밖의 4xx  모델이 답을 거부했다
                     시간 초과          모델이 이미 돌았을 수 있다 — 비용이 두 번 나갈 수 있다
                     계약 위반          재시도가 아니라 수리 1회가 맡는다 (ADR-033)
   ```
2. **자리는 `client.py` 한 곳이다** — `post_json` · `post_stream` 둘 다. 연간 · 월간 · 주간 · 일지 · jev 가 모두 이 문을 지나므로
   한 번에 같은 규칙을 받는다. 기능마다 따로 넣지 않는다.
3. **재시도도 호출 한 번으로 센다.** 끊긴 시도는 `llm_call ... outcome=not_delivered` 한 줄을 남긴다. retry 횟수 = 이 줄의 수다(§21).
   `llm_usage`(토큰 · 비용)는 성공한 호출만 남기는 그대로다.
4. **스트림은 첫 줄을 받기 전까지만** 다시 보낸다. 답이 오기 시작한 뒤 끊기면 모델이 이미 돌았으므로 지금처럼 실패다.

## 하지 않는 것

- **Rule 후보만으로 만든 초안(RULE_ONLY 폴백).** 놀이 연간 · 놀이 월간은 Rule 이 가진 것이 누리과정 내용뿐이라 채울 놀이가 없다.
  「AI 없이 만든 초안」이 뜨면 교사가 품질이 낮은 초안을 그대로 쓸 수 있다. 실패는 실패로 보여 준다.
- **시간 초과 재시도 · 2회 이상 재시도.** 비용이 두 번 나갈 수 있고, 교사가 기다리는 시간이 30초씩 늘어난다.

## 결과

- 순간적인 게이트웨이 끊김은 교사 화면에 닿지 않는다. 늘어나는 시간은 끊긴 경우에만 약 1.5초다.
- 구간을 여러 번 부르는 생성에서 한 구간만 끊겨 전체를 버리는 일이 줄어든다. 실패한 구간만 다시 부르는 것은
  놀이 연간 병렬 생성 작업에서 따로 다룬다.
- 테스트 — `backend/tests/test_llm_usage_log.py`(다시 보냄 · 다시 보내지 않음 · 두 번째도 실패) · `backend/tests/test_llm_stream.py`(503 뒤 성공).
