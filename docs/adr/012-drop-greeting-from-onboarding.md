# ADR-012: 성품인사를 온보딩에서 뺀다

- 2026-09-14 결정 / 2026-09-16 반영
- 상태 — 채택

## 맥락

`.planning/결정.md` §0 「성품인사는 월별로 바뀐다 `[실측]`」 이 온보딩 3단계에
성품인사 12칸을 넣게 했다.

그 근거는 **원 1곳의 월간계획안**이었다.

```
5월   긍정적인 어린이가 되겠습니다
9월   약속을 잘 지키는 어린이가 되겠습니다
```

3장이 모두 5월이라 처음엔 "원 단위 고정 1개"로 적었다가, 9월 문서를 보고
"원 단위 × 월 단위 12개"로 고쳤다. **표본이 계속 같은 원 1곳이었다.**

## 결정

**온보딩에서 뺀다.** 화면 번호 S4 는 비워 둔다 — 이미 공유한 S5~S9 를 밀지 않는다.

```
전   S1 원 정보 → S2 반 정보 → S3 아동 명단 → S4 성품인사
후   S1 원 정보 → S2 반 정보 → S3 아동 명단
```

**기능은 지우지 않는다.** 설정 화면(7주차)으로 옮기고 **기본 off** 로 둔다.

## 근거

**판독 가능한 20개 중 0개다** `[실측: 표본 20]`

충청북도 정보공개포털 수집분 23개를 `pdftotext -layout` 으로 훑었다.

| | 수집 | 판독 가능 | 성품인사 |
|---|---|---|---|
| 연간계획안 | 18 | 15 | **0** |
| 월간계획안 | 5 | 5 | **0** |

**3개는 스캔 이미지라 텍스트 레이어가 없다** — 지오숲·진천(0자), 공립바른(129자).
OCR 없이는 못 읽는다. 판정에서 제외했다.

「기본생활」이 4건 잡혔으나 **기본생활습관 영역**이고 성품 다짐 문구가 아니다.

**성품교육 프로그램을 도입한 원의 관행이다** `[판단]`

경청·긍정적인 태도·기쁨·배려·감사·인내·책임감·절제·정직을 월별로 돌리는 건
특정 성품교육 커리큘럼의 구성이다. 업계 표준 서식이 아니다.

**온보딩 비용이 크다** `[판단]`

12칸을 채우게 하는 단계 하나다. **22/23 원이 쓰지 않는 화면**을 전원이 지나간다.
온보딩 이탈은 되돌릴 수 없다 — 안 쓰기로 한 사람은 다시 안 온다.

## 대안

**토글만 온보딩에 남긴다** — 「사용 안 함」 체크 하나. 단계는 그대로 남아서
22/23 이 여전히 그 화면을 본다. 이탈 지점을 없애지 못한다.

**기능 자체를 삭제한다** — 쓰는 원에서는 계획안 상단이 비어 문서가 미완성이 된다.
실측 1건이 0건은 아니다.

## 결과

- §0 「성품인사는 월별로 바뀐다」의 **결론(원 단위 × 월 단위 12개)은 유지한다.**
  적용 위치만 바뀐다.
- `GET·PUT /api/centers/{id}/greetings` 계약은 그대로. **호출 지점만 온보딩 → 설정.**
- `enabled` 기본값을 `true` → **`false`** 로 바꾼다.
- 설정 화면(S10)은 7주차 범위다. 6주차에는 성품인사 화면이 없다.

## 교훈

**표본 1개로 정한 것은 표본이 늘면 뒤집힌다.** ADR-008(기후 프로파일 삭제)과 같은 성격이다.
`[실측]` 라벨에 **표본 수를 같이 적는다** — "실측"이 "1개를 봤다"인지 "23개를 봤다"인지가
결정의 수명을 정한다.
