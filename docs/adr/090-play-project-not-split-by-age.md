# ADR-090: 놀이 프로젝트형 연간은 연령에 따라 놀이를 나누지 않는다

- 2026-11-10
- 상태 — 채택 (하민 결정 2026-11-10: 현직 교사 의견 「놀이중심형은 연령을 구분하지 말고 놀이 프로젝트를 진행한다」를 따른다). 실제 생성 재측정 2026-11-10 완료(아래 「재측정」).
- 관련 — [ADR-042](042-yearly-v2-common-and-format-contracts.md) §4(누리과정 내용 ID 를 연령으로 나누지 않는다) · [ADR-077](077-play-annual-parallel-periods-retry-overlap.md)(v7) · CLAUDE.md §5 · §6 · api-spec §4

## 맥락

v7 지시문은 놀이 이름을 「그 시기 · 연령 유아의 호기심이 떠오르는 놀이 이름」으로 쓰게 했다.
그래서 반 연령(`ages`)이 놀이의 수준과 표현을 정하는 입력이었다.

현직 교사는 놀이중심형에서는 연령으로 놀이를 구분하지 않는다고 했다. 놀이는 유아의 관심에서 시작하기 때문이다.
2019 개정 누리과정도 59개 내용을 3~5세 공통으로 제시한다(ADR-042 §4).

그렇다고 연령을 입력에서 아예 빼면 만 3세 반에 위험한 재료가 나와도 막을 장치가 없다.
놀이 연간에는 Rule 쪽 연령 필터가 따로 없어서다. 연령 적합성과 안전성은 선별 우선순위 1 · 3순위다(CLAUDE.md §6).

## 결정

1. 지시문에서 놀이 이름의 연령 기준(「연령 유아의」)을 뺀다. 놀이를 연령에 따라 나누거나 수준 · 표현을 달리 쓰지 않는다.
2. `ages` 는 입력에 남긴다. 쓰임은 「그 연령 유아에게 위험하거나 맞지 않는 재료 · 놀이 방식을 쓰지 않는다」로 좁힌다.
3. 프롬프트 판은 `play-project-planner-v7` → `play-project-planner-v8` 이다. 출력 형식 · Validation · Rule 힌트(`play_seeds`)는 바뀌지 않는다.
4. 범위는 놀이 프로젝트형 연간뿐이다. 놀이 월간(`play_monthly`)도 `ages` 를 입력으로 넘기지만 연령 지시문은 없다. 놀이 월간에도 같은 원칙을 적용할지는 따로 정한다.

## 결과

- 이미 저장된 계획의 `rule_version` 은 v7 그대로다. 새로 만든 칸부터 v8 이다.
- v7 측정값(ADR-077: 시간 · 반복 · 사람 판정)은 v8 에 그대로 옮기지 않는다. 지시문이 바뀌었으므로 다시 재야 같은 계약이라고 말할 수 있다.

## 재측정 (2026-11-10, [runs/2026-11-10-play-age-v8](../evaluation/runs/2026-11-10-play-age-v8/))

v7 · v8 × 만 3 · 만 5 각 3회, v8 혼합 만 3+4+5 3회(호출 60회, 2,583원).

- 계약 · 시간: 15/15 검증 통과, 실패 · 재호출 · 겹침 교체 0. 회당 48~53초로 v7 과 같다.
- **연령끼리 이름 겹침은 연령 중립성을 재는 지표가 되지 못했다.** v7 · v8 모두 연령끼리 겹침이 같은 연령 회끼리 겹침과 같은 수준(거의 0)이다. 생성마다 무작위로 뽑는 `play_seeds` 가 놀이를 정하기 때문이다. 그래서 이 ADR 의 근거는 측정 개선이 아니라 교사 의견 · 누리과정 출처이고, 재측정은 「v8 로 바꿔도 계약 · 시간 · 재료 안전이 나빠지지 않았다」를 확인한 것이다.
- 글 수준(이름 · 지원 방향 · 문장 길이)과 연령 낱말(0건)은 v7 · v8 이 같다. 연령이 드러난 곳은 준비물이다(꾸밈 없는 「가위」는 만 5 에서만, 「큰 · 매끈한 · 유아용」 꾸밈은 v8 이 조금 많음 — 3회라 우연과 구분 못 함).
- 연령 중립성을 직접 재려면 같은 `play_seeds` 를 고정하고 연령만 바꾼 짝 비교가 필요하다. 이번에는 하지 않았다.
- 만 3 이 들어간 반의 작은 재료(강낭콩 등)를 Rule 로 거르는 안은 하민이 기각했다(2026-11-10).

[의견] 현직 교사(2026-11-10, 하민 전달): 놀이중심형은 연령 구분 없이 놀이 프로젝트를 진행한다.
[출처] 2019 개정 누리과정 해설서 PDF p.19 · 37 · 38 · 60: 59개 내용은 연령 구분 없이 3~5세가 모두 경험할 수 있는 내용이다(ADR-042 §4 와 같은 출처).
[판단] 연령을 입력에서 아예 빼지 않고 안전 판단용으로만 남긴다. 연령 적합성 · 안전성 우선순위(CLAUDE.md §6)를 지키면서 교사 의견을 따르는 가장 좁은 변경이다.
