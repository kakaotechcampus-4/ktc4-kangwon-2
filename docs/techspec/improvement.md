## 1. 놀이 프로젝트형 연간 (v2) — 순차 → 동시 (#464, ADR-077, develop 2026-11-09)

### 문제

- 4구간을 차례로 불러 **평균 149.7초**가 걸렸다. 교사가 2분 넘게 기다린다.
- 한 구간이라도 실패하면 앞 구간까지 **모두 버렸다**.
- 다시 만들면 같은 구간에 같은 놀이가 또 나왔다(40개당 1.91개).

### 바꾼 것

| 무엇 | 내용 |
|---|---|
| 동시 호출 | 4구간을 한 번씩 동시에 부른다. 호출 수 · 비용은 순차와 같다(4번) |
| Rule 힌트 | 앞 구간 이름을 넘길 수 없으므로, Rule이 후보마다 출발점을 정한다. 누리과정 내용 1개(한 해 40개 모두 다르게, 생활 · 안전 8개 제외 59 → 51) · 해설서 p.48-49 자료 종류 6가지 중 1개 |
| 힌트 반영 검사 | 배움 칸 근거에 힌트의 내용 id가 없으면 `SEED_CONTENT_MISSING` |
| 실패 구간만 다시 | 호출 깨짐 · 시간 초과 · 계약 위반인 구간만 같은 입력으로 한 번 더 부른다 |
| 겹친 후보만 다시 | 구간끼리 이름이 비슷하면 나중 구간 후보만, 나머지 39개를 피할 목록으로 넘겨 한 번 다시 만든다 |
| 판 올림 | `play-project-planner-v6` → `v7`. 프롬프트 · 입력 · 검사가 바뀐 계약 변경이라서다 |

### 어떻게 골랐나 — 조건 넷을 10회씩

| 조건 | 내용 | 결과 |
|---|---|---|
| ① 순차 | 지금 방식(기준선) | 사람 1.30 · 150초 |
| ⑤ 동시 + 누리 힌트 | | 사람 판정 ①과 같음 · jev B1 49(낮음) |
| ⑥ ⑤ + 자료 힌트 | | 사람 ✗ 8로 ①보다 나쁨 |
| **⑦ ⑥ − 생활 · 안전 힌트** | 힌트로 뽑는 누리과정 내용에서 1.2 건강 · 1.3 안전 8개를 뺌 | **사람 1.35 · 38초 → 채택** |

### 결과

| | ① | ⑦ |
|---|---|---|
| 시간 평균 | 149.7초 | **38.3초** |
| 다른 이름 수 / 400 | 362 | **397** |

### 대가 · 남은 것

- **jev B2(이름만 읽어도 알겠나) 19 → 39, B6(억지 조합) 16 → 22.** 사람 판정에서는 못하지 않았지만, 이름이 길고 조합이 많아진 경향은 있다.
- 실패 · 겹침 재생성 경로는 가짜 LLM으로만 확인했다(실측 30회에서 0건).
- 겹침 검사기는 같은 놀이 24짝 중 6짝만 잡는다. 뜻으로 묻는 판정은 하지 않았다(호출 · 지연 증가).
- 최악의 대기는 세 단계 × 120초 = 6분이다.

## 2. 주간 활동 후보 — 반복 줄이기 (`feature/weekly-prior-week-dedup`, PR 대기)

### 문제

- 같은 주를 다시 만들어도 후보 근거가 **똑같았다**(근거 겹침 1.00). 근거 검색이 결정적이기 때문이다.
- 같은 달의 주들이 같은 질의로 검색해서 **주마다 같은 근거**가 나왔다(주끼리 1.00). 대·소집단 후보는 월 주제로만 검색한다(ADR-054, 11-01 결정 — 주간 소주제와 맞추지 않음). 실내놀이는 소주제도 질의에 넣지만, 이번 실측의 월간에는 소주제 칸이 없었다.
- 교사 입장에서는 「다시 만들기」를 눌러도 같은 것이 나오고, 4주 내내 비슷한 후보를 보게 된다.

### 단계별로 바꾼 것과 다시 잰 결과

| 단계 | 바꾼 것 | 다시 잰 결과 | 새로 생긴 문제 |
|---|---|---|---|
| 1 (11-09) 앞 주 근거 미루기 | 같은 반 · 같은 달 앞 주차가 후보에 쓴 근거를 뒤로 보낸다. 모자랄 때만 덜 쓴 것부터 채운다 | 한 달 주끼리 근거 겹침: 대·소집단 1.00 → 0.32, 실내놀이 1.00 → 0 | 풀 깊은 곳의 「[절기놀이]」 같은 태그 제목 → 5주차 500. 고침 |
| 2 (11-10) 상위 20건에서 섞기 | 생성마다 seed로 상위 20건 중 10건을 뽑는다. 다시 만들기 · Golden은 seed 없음(결정적) | 같은 주 다시 만들기 근거 겹침 1.00 → 0.33~0.35, 한 달 주끼리 0~0.25 | ① 추출이 잘린 기록 2건 → 12월 5주차 500. 검토 목록에 넣어 고침. ② **만5 정확 연령 근거 비율 0.60 → 0.42**(같은 주) · 0.28(한 달) |
| 3 (11-10) 연령 등급 안에서만 섞기 | 정확 연령 기록부터 채우고, 넘치는 등급만 그 등급 상위 20건 안에서 활동 종류별로 돌아가며 뽑는다. seed는 로그에만 두고 계획안 본문에는 저장하지 않는다(하민 11-10) | 시뮬레이션(호출 0회, seed 50개): 만5 실내놀이 정확 연령 비율 0.42 → **0.84**. 실제 생성에서도 0.42 → 1.00 | 사람 판정에서 효과 없음 · 만4 「기타」 쏠림(아래) |
| 4 (11-10) **3단계를 뺐다** | 상위 20건 전체에서 섞되, 활동 종류별로 돌아가며 뽑는다. 혼합연령 반은 요청 연령마다 1건을 먼저 남긴다(PR #469 리뷰). seed는 로그에만 둔다(하민 11-10) | 시뮬레이션(호출 0회): 실내놀이 종류 수 고정 상위 10보다 많음, seed끼리 겹침 0.54~0.56 | 실제 생성(35회): 실내놀이 같은 주 겹침 0.35 · 종류 7.0, 만4 「기타」 81 → 15개. 만4 대·소집단 겹침은 0.55(2단계 0.35) |

### 3단계를 왜 넣었고 왜 뺐나

| 만5 실내놀이, 12개월 평균 (시뮬레이션) | 고정 상위 10 | 2단계 무작위 | 3단계 등급 우선 | **4단계 종류 순환 (최종)** |
|---|---|---|---|---|
| 정확 연령 비율 | 0.42 | 0.38 | 0.84 | 0.36 |
| seed끼리 근거 겹침 (낮을수록 다양) | 1.00 | 0.50 | 0.70 | 0.54 |
| 후보 10건 안의 활동 종류 수 | 6.3 | 5.9 | 5.2 | **6.9** |

- **넣은 이유:** 2단계에서 정확 연령 근거 비율이 떨어졌고, 선별 1순위가 연령 적합성이라서(CLAUDE.md §6) 등급 우선을 넣었다.
- **뺀 이유:** 근거 등급을 가린 사람 판정에서 정확 연령 기록이 연령 적합으로 더 낫지 않았다(아래). 「정확 연령 비율」은 근거의 연령 표기를 센 것이지 적합성을 잰 것이 아니었다. 대신 다양성과 주제 적합을 잃고 만4 「기타」 쏠림이 생겼다(하민 결정 2026-11-10).
- 4단계는 만4 실내놀이 종류 수도 6.1 → 6.8로, 3단계 실측(2.9)의 쏠림이 풀린다(시뮬레이션). 전체 표: `runs/2026-11-10-weekly/final_shuffle_sim.md`.

### 근거 충실도는 그대로인가

- jev 근거 대조(중복 뺀 651개): ○ 311 · △ 334 · ✗ 6.
- 형식 100% · 고쳐 쓰기 0회 · 비용 · 시간은 그대로다(주간 1회 중앙값 89원 · 26~28초).

### 남은 것

- **근거 7~12건 칸**(12월 대·소집단 등)은 바뀌지 않는다. 「다른 달 근거까지 넓히기」는 계절 기준이 먼저 필요하다.
- **주제 적합:** 섞으면 질의와 덜 맞는 근거가 들어온다. jev T1 벗어남 비율이 올랐지만, 그 판정은 사람과 맞지 않았다([evaluation.md](evaluation.md) §4).
  - 대·소집단은 월 주제로만 검색하므로 소주제가 있는 월간으로 다시 재도 질의가 바뀌지 않는다. 대·소집단 순위에 주간 소주제는 더하지 않는다 — ADR-054 그대로(하민 2026-11-10).
  - 실내놀이는 소주제를 질의에 쓰므로, 소주제가 있는 월간으로 다시 재면 달라질 수 있다.
- 최종(4단계) 실제 생성(Sol 35회 ≈ 2,827원): 실내놀이 같은 주 근거 겹침 0.35(2단계 0.33), 활동 종류 7.0, 만4 「기타」 81 → 15개. 만4 대·소집단은 0.55로 2단계(0.35)보다 높다 — 근거가 19건이라 상위 20건이 거의 전부다. 표: `runs/2026-11-10-weekly/` 「최종 실제 생성」. 순환 건수를 처음 5건·3건으로 줄이면 겹침이 0.05~0.09 내려가지만 종류가 1.5~2개 줄어(시뮬레이션 `runs/2026-11-10-weekly/rr_limit_sim.md`), 종류 수를 택한 결정을 유지했다.

### 3단계 실제 생성 확인 — 뺀 근거 (11-10, Sol 35회 ≈ 2,833원)

| 반 · 칸 (같은 주 10회) | 근거 겹침 (섞기 전 → 2단계 → 3단계) | 정확 연령 비율 (2단계 → 3단계) | 영역 · 유형 수 (2단계 → 3단계) |
|---|---|---|---|
| 만4 · 11월 대·소집단 | 1.00 → 0.35 → 0.51 | 0 → 0 (단일연령 기록 없음) | 5.1 → 7.0 |
| 만4 · 11월 실내놀이 | 1.00 → 0.33 → 0.71 | 0.18 → **0.80** | 5.7 → **2.9** |
| 만5 · 12월 대·소집단 (근거 7건) | 1.00 → 1.00 → 1.00 | 0.43 → 0.43 | 5.0 → 5.0 |
| 만5 · 12월 실내놀이 | 1.00 → 0.33 → 0.73 | 0.42 → **1.00** | 6.2 → 5.0 |

- 정확 연령 근거는 시뮬레이션 예상대로 돌아왔다. 같은 주를 다시 만들 때의 다양성은 2단계보다 줄었지만, 섞기 전(1.00)보다는 낫다.
- 한 달 안의 주끼리는 그대로다(실내놀이 0, 대·소집단 0.26).
- **새 문제:** 만4 실내놀이 후보의 81%가 영역 「기타」다(2단계 23%). 만4 단일연령 실내놀이 기록은 원문에서 영역을 확인할 수 없는 자료가 많은데, 등급 우선이라 이 기록이 먼저 들어온다.
- 형식 535/535, 고쳐 쓰기 0회, 주간 29회 모두 성공, 1회 중앙값 89원 · 26~28초.
