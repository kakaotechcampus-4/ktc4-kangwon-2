## 2. 주간 활동 후보 — 반복 줄이기 (#469)

### 문제

- 같은 주를 다시 만들어도 후보 근거가 **똑같았다**(근거 겹침 1.00). 근거 검색이 결정적이기 때문이다.
- 같은 달의 주들이 같은 질의로 검색해서 **주마다 같은 근거**가 나왔다(주끼리 1.00). 대·소집단 후보는 월 주제로만 검색한다(ADR-054, 11-01 결정 — 주간 소주제와 맞추지 않음). 실내놀이는 소주제도 질의에 넣지만, 이번 실측의 월간에는 소주제 칸이 없었다.
- 교사 입장에서는 「다시 만들기」를 눌러도 같은 것이 나오고, 4주 내내 비슷한 후보를 보게 된다.

## 3. 고도화 — 다음 단계

재 보고 다음 단계로 둔 것들이다. 다른 문서의 「다음에 넓힐 것」도 모두 여기로 모았다. 항목마다 「지금(잰 숫자) → 지금 이렇게 둔 이유 → 고도화 방안 → 크기」 순서로 적는다. 크기는 「작음 = 함수 하나 + 테스트」, 「중간 = 여러 파일 · 계약이나 판 변경」, 「큼 = 새 자료 · 새 모델 · 사람 검토」로 어림한다.

### 3분 설명 — 꼭 말할 다섯 가지

발표 · 질의응답에서 이 순서로 말한다. 한 항목에 30~40초.

1. **Rule이 고르면 결과가 바뀐다 — 그림책에서 확인했고, 유튜브로 넓힌다.**
   그림책 6권을 LLM에게 넘겨 고르게 했을 때는 후보에 쓰인 책이 0권이었다. Rule이 자리와 책을 정해 주자 6번 중 6번 쓰였고, 고쳐 쓰기 0회, 지어낸 줄거리 0건이었다. 같은 방식을 유튜브 트렌드에 적용한다. 주제 낱말로 영상을 먼저 거르고, 맞는 영상이 있을 때만 Rule이 자리를 준다.
2. **검색은 설명 가능한 글자 겹침으로 시작했고, 임베딩은 순위 보조로 더한다.**
   근거 12,324건을 월 · 칸 · 연령으로 거르면 비교 대상은 수십~수백 건이다. 지금은 「연령 정확 일치, 주제 낱말 3개 겹침」처럼 왜 골랐는지 말할 수 있고, Golden 테스트가 결정적이다. 다음은 Rule 필터 안에서 임베딩을 보조 점수로 더해 「가을」 질의가 「낙엽 · 단풍」 기록까지 닿게 하는 것이다. 판은 고정하고, 저장은 지금 쓰는 Postgres에 pgvector로 충분하다.
3. **반복 줄이기는 재면서 단계로 간다.**
   주간 후보는 같은 주 근거 겹침을 1.00에서 0.35로 낮췄다. 놀이 월간 대피 후보는 달마다 시작점을 돌려, 연속한 두 달이 같은 묶음인 경우를 8쌍에서 3쌍으로 줄였다. 다음은 근거가 7~19건인 칸에 「같은 계절로 볼 달」 기준을 정해 이웃 달 근거를 더하고, 대피 문장은 공식 자료의 상황별 행동을 catalog 새 판에 더해 입력 단계에서 다양하게 만드는 것이다.
4. **LLM 평가는 내부 참고 지표로 쓰고, 사람 판정으로 넓혀 간다.**
   좁힌 jev 질문은 사람 판정과 26건 중 22건이 같았고, 세 번 돌려도 같았다. 이 질문은 그 26건을 보며 다듬었으므로, 다음은 새 표본 30건에 사람 판정을 받아 질문을 그대로 둔 채 견주는 것이다. 판정자끼리 갈린 주제 판단은 기준을 정했고, 같은 후보를 그 기준으로 다시 판정한다. jev는 저장 여부를 정하지 않고 교사 화면에도 나오지 않는다.
5. **속도와 안정성은 기록을 더 남기는 쪽으로 간다.**
   놀이 연간은 동시 생성으로 150초에서 38초가 됐고, 배포 서버 재측정 10회도 모두 첫 시도에 통과했다. 실패 구간 · 겹친 후보 재생성은 가짜 LLM Golden으로 고정해 두었다. 다음은 재생성이 실제로 몇 번 쓰였는지 응답에 숫자로 남기고, 구간별 저장 · 작업 큐로 긴 생성도 이어서 만들게 하는 것이다.
