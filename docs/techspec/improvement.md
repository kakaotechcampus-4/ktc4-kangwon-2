## 2. 주간 활동 후보 — 반복 줄이기 (#469)

### 문제

- 같은 주를 다시 만들어도 후보 근거가 **똑같았다**(근거 겹침 1.00). 근거 검색이 결정적이기 때문이다.
- 같은 달의 주들이 같은 질의로 검색해서 **주마다 같은 근거**가 나왔다(주끼리 1.00). 대·소집단 후보는 월 주제로만 검색한다(ADR-054, 11-01 결정 — 주간 소주제와 맞추지 않음). 실내놀이는 소주제도 질의에 넣지만, 이번 실측의 월간에는 소주제 칸이 없었다.
- 교사 입장에서는 「다시 만들기」를 눌러도 같은 것이 나오고, 4주 내내 비슷한 후보를 보게 된다.

## 3. 고도화 — 알고 남긴 한계

재 보고 일부러 다음으로 미룬 것들이다. 항목마다 「지금 한계(잰 숫자) → 왜 지금 안 했나 → 고도화 방안 → 크기」 순서로 적는다. 크기는 「작음 = 함수 하나 + 테스트」, 「중간 = 여러 파일 · 계약이나 판 변경」, 「큼 = 새 자료 · 새 모델 · 사람 검토」로 어림한다.

| 한계 | 지금 (잰 숫자) | 왜 지금 안 했나 | 고도화 방안 | 크기 |
