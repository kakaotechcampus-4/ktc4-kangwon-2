# 에이전트 설계 — 계획안

[테크스펙 요약](README.md)의 「A AI 동작 규격」과 「계획 변경 · 재개」를 자세히 적는다.

## 1. 한 줄 원칙 — Rule이 범위를 정하고, LLM이 그 안에서 정하고, Rule이 검사한다

```
Rule   허용 범위    승인된 후보 · 근거 · 제약 · 칸 구조 · 법정 기준
LLM    범위 안에서  값의 의미 내용을 고르고 구성하고 쓴다
Rule   검사         계약 · 근거 · 연령 · 법정 기준을 어겼는지
교사   확정         고치고, 고르고, 확정한다. 자동 확정 · 자동 제출은 없다
```

- ADR-032가 연간 · 월간 · 주간 공통으로 정했다. 결정이 바뀐 기록도 남아 있다: ADR-005(「LLM은 문장화만」) → ADR-014가 대체 → ADR-032가 보충.
- `RULE_LLM`의 뜻(2026-09-26)은 「Rule이 허용한 후보 · 근거 · 제약 안에서 LLM이 값의 의미 내용을 정한 것」이다. LLM은 문장만 다듬는 역할이 아니다.
- 범위 밖의 것은 LLM이 정하지 않는다. 승인 목록에 없는 id, 근거 없는 사실, 통과 여부가 그렇다.

**왜 이 정도의 자율성인가.** 보육 계획안에는 틀리면 안 되는 값이 있다. 법정 안전교육 주기 · 연령 적합성 · 실제로 있는 행사가 그렇다. 반대로 교사가 가장 시간을 쓰는 곳은 「이번 주에 무슨 놀이를, 어떤 말로」다. 그래서 틀리면 안 되는 값은 Rule에, 판단과 표현이 필요한 값은 LLM에 두었다. LLM이 도구와 단계를 스스로 고르는 에이전트 루프는 이 문제에서 이득보다 검증 부담이 크다(트레이드오프 → [README](README.md) §12).

## 2. 계획안별로 누가 무엇을 정하나

| 계획안 | Rule이 정하는 것 | LLM이 정하는 것 | 교사가 하는 것 |
|---|---|---|---|
| 연간 · 월별 주제형 | 월 · 연령에 맞는 Theme 후보를 활성 Catalog에서 고른다 | 고른 `theme_id`의 문장 (id는 못 바꾼다) | 고친다 · 확정 |
| 연간 · 놀이 프로젝트형 | 후보마다 출발점 둘 — 누리과정 내용 1개(한 해 40개 모두 다르게) · 해설서 자료 종류 1개 | 놀이 이름 · 준비물 · 지원 방향 · 배움 칸 | 구간마다 10개 중 5개 고른다 |
| 월간 · 주제형 | 칸 구조, 법정 안전교육 대조, 안전교육 후보 8개, 승인 근거 묶음 | 칸 내용 · 문장 | 주마다 안전교육 고른다 · 고친다 · 확정 |
| 월간 · 놀이형 | 근거 · 트렌드 자료 묶음, 후보 수 | 후보 8개 | 5개 고른다 |
| 주간 | 같은 달 · 같은 연령 · 같은 분류의 기관 근거를 찾고, 앞 주가 쓴 근거는 뒤로 미루고, 연령 등급 안에서 10건을 뽑는다 | 그 근거 안에서 활동 이름 · 설명 | 후보 중 고른다 · 요일 칸에 나눈다 · 확정 |
| 기존 연간 가져오기 | 배정 글자가 원문에 그대로 있는지 검사 | 원문 글자를 어느 칸에 둘지 배정 | 표에서 확인해야 저장 |

## 3. 호출 구조

- **모델:** 생성은 Sol(`openai/gpt-6.1-sol`)이다. 판정 모델 jev는 일지 3단 게이트 · 트렌드봇 검열에만 쓴다(ADR-070 · 071). 계획안에서는 품질 측정에만 쓴다.
- **한 문을 지난다:** `backend/app/shared/llm/client.py`. 성공한 호출마다 `llm_usage` 한 줄(모델 · 토큰 숫자)을 남기고, 프롬프트 · 응답은 남기지 않는다 — ADR-036
- **문서 단위로 한 번에 부른다.** 연간 12개월 · 월간 한 달 · 주간 한 주를 한 번에 부른다. 놀이 연간은 구간마다 한 번씩, 4번을 동시에 부른다.
- **시간 제한:** 한 호출 30초. 놀이 연간 스트리밍은 구간마다 120초를 감시한다.
- **판(version)을 남긴다.** 프롬프트 · 입력 · Validation이 바뀐 계약 변경이면 `rule_version`을 올린다. 예: `play-project-planner-v6` → `v7`(ADR-077). 결과가 달라졌다는 이유만으로는 올리지 않는다.

## 4. 계획 변경

| 변경 | 동작 | 근거 |
|---|---|---|
| 상위가 확정 전 | 하위 생성을 막는다(409 게이트) | CLAUDE.md §2 |
| 교사가 칸을 고침 | 값만 바꾸고 `TEACHER_EDITED` 이력을 남긴다. 원래 근거와 만든 방식은 지우지 않는다 | CLAUDE.md §13 |
| 칸 하나만 다시 | 그 칸만 다시 만든다. 다른 칸의 id · 값 · 근거는 그대로다. 이전 값과 방식은 `REGENERATED` 이력에 남는다 | `golden/cell_regeneration.json` · `golden/weekly_cell_regeneration.json` |
| 확정을 풂 | 문서 보관함 「수정하기」 → 초안(`UNCONFIRMED`). 하위 계획안에 `parent_changed`가 표시된다 | ADR-055 · 064 |
| 하위가 있는 상위를 지움 | 409로 막는다 | ADR-064 |
| 동시 수정 | 월간은 revision, 연간은 서버 행 잠금. 확정 재호출은 200(멱등) | ADR-035 |
| 상위 값이 하위에 들어가는 방식 | 칸에 그대로 복사하지 않고 맥락 · 제약으로 쓴다. 교사가 고쳐 확정한 값이 이전 AI 원본보다 우선한다 | CLAUDE.md §6 |
| 같은 달 다음 주 주간 | 앞 주가 후보에 쓴 근거는 뒤로 미룬다. 여러 주가 쓴 만큼 센다 | PR 대기 · [improvement.md](improvement.md) §2 |

## 5. 중단과 재개

| 상황 | 동작 | 근거 |
|---|---|---|
| 놀이 연간에서 한 구간 실패 (호출 깨짐 · 시간 초과 · 계약 위반) | 그 구간만 같은 입력으로 한 번 더 부른다. 성공한 구간은 버리지 않는다 | ADR-077 §3 |
| 다시 불러도 같은 실패 (한도 · 키 없음 · 설정 오류 · Reference 미승인 · 메모 가명 실패) | 다시 부르지 않고 바로 그 오류를 낸다 | ADR-077 §3 |
| 놀이 연간 구간끼리 후보 겹침 | 겹친 후보만 다시 만든다. 나머지 39개를 피할 목록으로 넘기고, 같은 자리 · 같은 `row_key`에 넣는다. 교사 요청을 반영한 후보는 바꾸지 않는다 | ADR-077 §4 |
| 교사가 「생성 멈추기」 | 동시 호출 전 · 다시 부르기 전 · 저장 전에 끊김을 보고, 끊겼으면 저장하지 않는다 | ADR-077 §5 |
| 저장 전 어디서든 실패 | 모든 단계가 통과한 뒤에 한 번만 저장한다. 반쯤 된 계획안은 없다 | ADR-077 · `test_create_document_saves_nothing_when_generation_fails` |
| 주간을 다시 만듦 | 매번 새 seed로 근거를 다시 뽑아 다른 후보가 나온다. seed는 서버 로그에만 남고 계획안 본문에는 저장하지 않는다(하민 11-10). 실제로 쓴 근거는 칸 근거에 남는다 | PR 대기 · [improvement.md](improvement.md) §2 |

**하지 않은 것:** 구간별 저장 · 작업 큐로 이어서 하기. 동시 생성으로 38초가 됐고, 반쯤 저장된 상태를 다루는 비용이 더 크다.

## 6. 실패했을 때 교사가 보는 것

| 상황 | 동작 | 화면 |
|---|---|---|
| 모델에 닿지 못함 (연결 거부 · 502/503/504) | 1.5초 뒤 한 번만 더 보낸다. 모델이 돌지 않았으니 비용이 두 번 나가지 않는다 | (보통 보이지 않음) |
| 시간 초과 · 429 · 401 · 403 | 다시 보내지 않는다 | — |
| 설정 없음 · 한도 초과 | 503 | 「운영 문의」 — 다시 눌러도 같으므로 「다시 시도」를 띄우지 않는다 |
| 답이 계약을 어김 | 수리 1회 → 그래도 어기면 500, 저장 안 함 | 「다시 시도」 |
| 트렌드봇 등 선택 자료 실패 | 그 자료 없이 생성하고 사용 여부를 기록한다 | 정상 생성 |
| 아동 이름 치환 실패 | 호출하지 않는다 | 422 |
| 반영 못 한 요청 사항 | 막지 않고 알린다 | `memo_notices` |

코드: `backend/app/shared/llm/errors.py` · `client.py` `_once_more`(ADR-076) · `elice_openai_monthly.py`(수리 1회, ADR-046 §5).
