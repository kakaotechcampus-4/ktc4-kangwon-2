# 평가 — 품질을 무엇으로 어떻게 쟀나

[validation.md](validation.md)는 시스템이 스스로 거르는 장치다. 이 문서는 **거르고 남은 결과가 쓸 만한지**를 사람 · 판정 모델 · 결정적 지표로 잰 방법과 결과다.
실행 기록(생성 글 · 판정 · 다시 세는 스크립트)은 `docs/evaluation/runs/`에 있다.

## 1. 평가 원칙

1. **기준선을 먼저 정한다.** 바꾸기 전 방식을 같은 조건으로 재고, 새 방식은 「기준선보다 못하지 않은가」부터 본다.
2. **같은 조건으로 여러 번 잰다.** 모델 온도가 고정(1)이라 같은 입력에도 답이 달라진다. 놀이 연간은 조건마다 10회, 주간은 같은 주 10회와 한 달 전체 주를 잰다.
3. **채택은 사람 판정으로 한다.** 조건을 가리고 기준선과 섞어서 ○(그대로 씀) · △(고치면 씀) · ✗(못 씀)로 본다.
4. **판정 모델은 사람과 맞춰 본 뒤에만 믿는다.** 맞지 않으면 참고 지표로 내린다.
5. **비용과 결과를 함께 남긴다.** 호출마다 토큰 · 원을 기록하고, 생성 글을 저장한다. 같은 결과를 호출 없이 다시 셀 수 있게 한다.
6. **생성 글은 기대값이 아니다.** 테스트는 모델 문장을 비교하지 않는다(ADR-023). 실행 기록으로만 둔다.

## 5. 기록 방식

- **호출마다:** 모델 · 입력/출력 토큰 · 시간 · 성공/실패 · 원. 프롬프트 · 키 · 아동 이름은 남기지 않는다.
- **실행마다 폴더 하나:** 조건 · 생성 글(공개 가능한 것) · 판정 결과 · 다시 세는 스크립트 · 비용.
- **판정 데이터:** 사람 판정은 JSON으로 남긴다(`human60.json` · `human7.json` · `dup-pairs.json`). 누가 언제 판정했는지도 적는다.
- **호출 없이 다시 세는 재고:** 실측 응답 · 서버 로그에서 Provenance 완결성 · Rule/LLM 비율 · 검증 작동 빈도 · 시간 · 토큰 · 테스트 규모를 표로 모았다 — `runs/2026-11-10-inventory/`. 셀 수 없는 것은 「없음」으로 적었다(audit 응답 · 치환 로그 · 11-08 배포 서버 토큰).

## 6. 아직 아닌 것

- 주간 사람 판정은 3단계 후보 117개와 최종 후보 51개(연령 · 주제)다. 3단계는 연령 ○ 0.88 · 주제 ○ 0.55, 최종은 0.82 · 0.55이고, 근거 등급(정확 연령 / 혼합연령)은 가리고 판정했다. 결과는 `docs/evaluation/runs/2026-11-10-weekly/human_judge_tally.json` · `human_judge_final.txt`. 근거 충실은 jev 대조 651개와 그중 26개를 판정자 한 명이 다시 본 것(다른 활동 0 · 덧붙임 6, 참고값)까지다.
- 주간 후보의 주제 적합은 앞 단계(섞기 전 · 2단계) 후보로는 사람이 재지 않았다. 대·소집단은 월 주제로만 검색하므로(ADR-054) 소주제 월간으로 바꿔도 질의가 같다. 대·소집단 순위에 소주제는 더하지 않는다(하민 2026-11-10).
- 품질을 사람이 판정한 것은 놀이 연간 · 주간이다. 주제형 연간 · 월간은 반복 · 근거 대조 · 사람 판정 30개(전부 ○)까지 쟀다. 놀이 월간은 반복만 쟀다.

- 교사가 실제로 고쳐 쓴 비율(초안 → 확정 사이 수정량)은 아직 모으지 않았다. 지표는 정했다: 확정 이력에 `TEACHER_EDITED`가 있는 칸의 비율. 실제 교사 사용 데이터가 없어 값이 없다.
- **판정자끼리 주제 판단이 갈린다.** 주간 주제 같음은 0.49, 놀이 연간은 같은 후보 60쌍 중 23쌍만 같다(§4). 주제 적합 기준은 정했지만(§4) 같은 후보를 그 기준으로 다시 판정하지 않았다. 일치가 낮은 원인의 상당 부분이 기준 차이라는 것은 추정이다(규칙이 분명한 유형에만 기준을 대면 0.83으로 어림). 표본도 작다(정확 연령 근거 25개).
- **근거가 적은 칸은 반복이 줄지 않는다.** 만5 · 12월 대·소집단은 근거 7건, 만4 · 11월은 19건이라 상위 20건 안에서 섞을 것이 없다(같은 주 근거 겹침 1.00 · 0.55). 그대로 둔다. 다른 달 근거로 넓히려면 계절 기준이 먼저 필요하다.
