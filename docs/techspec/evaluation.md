# 평가 — 품질을 무엇으로 어떻게 쟀나

[validation.md](validation.md)는 시스템이 스스로 거르는 장치다. 이 문서는 **거르고 남은 결과가 쓸 만한지**를 사람 · 판정 모델 · 결정적 지표로 잰 방법과 결과다.
실행 기록(생성 글 · 판정 · 다시 세는 스크립트)은 `docs/evaluation/runs/`에 있다.

## 1. 평가 원칙

1. **기준선을 먼저 정한다.** 바꾸기 전 방식을 같은 조건으로 재고, 새 방식은 「기준선보다 못하지 않은가」부터 본다.
2. **같은 조건으로 여러 번 잰다.** 모델 온도가 고정(1)이라 같은 입력에도 답이 달라진다. 놀이 연간은 조건마다 10회, 주간은 같은 주 10회와 한 달 전체 주를 잰다.
3. **채택은 사람 판정으로 한다.** 조건을 가리고 기준선과 섞어서 ○(그대로 씀) · △(고치면 씀) · ✗(못 씀)로 본다.
4. **판정 모델은 사람과 맞춰 본 뒤에만 믿는다.** 맞지 않으면 참고 지표로 내린다.
5. **비용과 결과를 함께 남긴다.** 호출마다 토큰 · 원을 기록하고, 생성 글을 저장한다. 같은 결과를 호출 없이 다시 셀 수 있게 한다.
6. **생성 글은 기대값이 아니다.** 테스트는 모델 문장을 비교하지 않는다(ADR-023). 실행 기록으로만 둔다.

## 2. 무엇을 재나

| 축 | 지표 | 어떻게 | 쓰는 곳 |
|---|---|---|---|
| 쓸 만한가 | ○ · △ · ✗ 비율, 평균(○2 △1 ✗0) | 사람 판정, 조건 가림 | 놀이 연간 |
| 근거에 충실한가 | 근거와 같은 활동인가 · 근거에 없는 재료 · 방법 · 사실을 더했나 | jev E1 · E2 · E3 → ○ · △ · ✗ | 주간 |
| 월 주제와 맞나 | 「같은 달 · 계절이라는 것만으로는 이어진다고 보지 않는다」 | jev T1 + 사람 확인 | 주간 |
| 놀이로서 괜찮은가 | 놀이다움 · 이름만 읽어도 알겠나 · 연령 · 준비물 · 억지 조합 · 지원 방향 · 배움 연결 | jev B1~B8, 기준선 하위 5% 선 밖의 수 | 놀이 연간 |
| 다양한가 | 다른 이름 수 · 계획 안 겹침 · 다시 만들 때 또 나온 이름 · 근거 겹침 · 5영역 고르기 | 결정적 계산 | 놀이 연간 · 주간 |
| 연령에 맞나 | 정확 연령 근거 비율 | 결정적 계산 | 주간 |
| 형식 | 「활동명: 설명」 · 합니다체 · 말투 섞임 · 이름 중복 · 근거에 없는 명사(상한 어림) | 결정적 검사 | 주간 |
| 누리과정 지침 | 고시문 Ⅱ-2 교수 · 학습 가~사를 낱말 검사로 | 결정적 검사(하한 어림) | 놀이 연간 |
| 속도 · 비용 | 시간 평균 · 중앙, 호출 수, 토큰 · 원 | 서버 로그 · `usage.log` | 전부 |

## 3. 결과 요약

**놀이 연간 v2** — `runs/2026-11-09-play-annual/` (Sol, 만4세, 조건마다 10회 = 후보 400개)

| | ① 순차 (기준선) | ⑦ 동시 + 힌트 (채택) |
|---|---|---|
| 사람 판정 평균 (같은 판정 안 20개씩) | 1.30 (○8 △10 ✗2) | **1.35** (○11 △5 ✗4) |
| 시간 평균 | 149.7초 | **38.3초** |
| 다른 이름 수 / 400 | 362 | **397** |
| 다시 만들 때 같은 구간에 또 나온 이름 / 40 | 1.91 | **0.15** |
| jev B2 이름이 분명함 (선 밖 수, 기준 ≈ 20) | 19 | 39 |
| jev B6 억지 조합 없음 | 16 | 22 |

- 사람 판정으로 「못하지 않음」을 확인하고 채택했다.
- jev 두 문항은 ⑦이 낮다. 이것을 숨기지 않고 [improvement.md](improvement.md)의 대가 칸에 적었다.

**주간 후보** — `runs/2026-11-10-weekly/` (Sol 45회 약 3,494원 + 3단계 확인 35회 약 2,833원 + jev 219회 약 25원 + 사람 판정 117개)

- 근거 충실(중복 뺀 후보 651개): **○ 311 · △ 334 · ✗ 6.** 근거와 다른 활동을 지어낸 것은 거의 없다. ✗는 근거에 없는 「역할놀이로」를 덧붙인 5개와 잘린 원문 1개다.
- 같은 주 다시 만들기 근거 겹침 1.00 → 0.33~0.35, 한 달 주끼리 1.00 → 0~0.25.
- 연령 등급 우선 시뮬레이션: 만5 실내놀이 정확 연령 비율 0.42 → 0.84.
- 형식 100% · 고쳐 쓰기 0회 · 주간 1회 중앙값 89원 · 26~28초.
- 월 주제 적합(jev T1)에서 벗어남으로 본 비율:

  | | 대·소집단 | 실내놀이 |
  |---|---|---|
  | develop | 10% | 1% |
  | 섞기 만4 11월 | 19% | 6% |
  | 섞기 만5 12월 | 37% | 32% |

  다만 이 판정은 아래 §4에서 사람과 맞지 않았다.

## 4. 측정 도구를 검증한 것

| 도구 | 어떻게 맞춰 봤나 | 결과 | 그래서 |
|---|---|---|---|
| jev 놀이 8문항 | 사람 판정 60개와 문항마다 방향 비교 | 같은 방향은 B1(놀이다움) 하나 | 참고 지표로만 쓴다. 채택은 사람 판정 |
| 겹침 검사기 (글자 두 개 묶음 Jaccard ≥ 0.6) | 하민이 라벨한 같은 놀이 24짝 · 다른 놀이 18짝 | 같은 놀이 6짝만 잡는다. 선을 0.3으로 낮추면 21짝을 잡지만 다른 놀이 9짝을 잘못 잡는다 | 글자로는 못 푼다. 테스트에 xfail로 남겼다(`test_play_dup_pairs.py`) |
| jev 월 주제 적합(T1) | 하민이 「이상하다」고 본 후보와 비교(11-10) | 하민이 주제와 동떨어졌다고 본 2개(「‘비눗방울’ 노래 부르기」 · 「블록으로 악기 가게 만들기」)를 jev는 0.52 · 0.77로 「맞다」 쪽에 두었다 | 주제 적합은 jev 수치로 결론 내지 않는다. 사람이 본다 |
| 「근거에 없는 명사」 검사 | 어미 · 바꿔 쓴 말도 걸린다 | 상한 어림이다(36~66%) | 실제 덧붙임은 jev E2 + 사람 확인으로 본다 |
| 누리과정 낱말 검사 | 고시문 문구를 낱말로 바꿈 | 하한 어림이다 | 비교용으로만 쓴다 |

## 5. 기록 방식

- **호출마다:** 모델 · 입력/출력 토큰 · 시간 · 성공/실패 · 원. 프롬프트 · 키 · 아동 이름은 남기지 않는다.
- **실행마다 폴더 하나:** 조건 · 생성 글(공개 가능한 것) · 판정 결과 · 다시 세는 스크립트 · 비용.
- **판정 데이터:** 사람 판정은 JSON으로 남긴다(`human60.json` · `human7.json` · `dup-pairs.json`). 누가 언제 판정했는지도 적는다.

## 6. 아직 아닌 것

- 주간 사람 판정은 3단계 후보 117개(연령 · 주제)만 했다. 연령 ○ 0.88 · 주제 ○ 0.55이고, 근거 등급(정확 연령 / 혼합연령)은 가리고 판정했다. 결과는 `docs/evaluation/runs/2026-11-10-weekly/human_judge_tally.json`. 근거 충실은 jev 대조와 하민 확인 일부까지다.
- 주간 후보의 주제 적합은 앞 단계(섞기 전 · 2단계) 후보로는 사람이 재지 않았다. 대·소집단은 월 주제로만 검색하므로(ADR-054) 소주제 월간으로 바꿔도 질의가 같다. 대·소집단 순위에 소주제는 더하지 않는다(하민 2026-11-10).
- 놀이 연간은 만4세 · 요청 없음만 쟀다.
- 교사가 실제로 고쳐 쓴 비율(초안 → 확정 사이 수정량)은 아직 모으지 않았다. 확정 이력(`TEACHER_EDITED`)으로 셀 수 있다.
