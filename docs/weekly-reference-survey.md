### 3-2. 주 단위 값 vs 요일 단위 값

- **대부분의 행은 주 전체에 값 하나다** `[실측]`.
- **요일마다 값이 다른 행은 대·소집단 활동 · 특별활동 · 행사 · 준비물뿐이다.**
- 실내놀이는 「주에 놀이 4~7개 목록」이지 요일별 배정이 아니다.

## 5. 동일 기관 연간 · 주간 매칭

### 5-1. 방법

연간 폴더(139개)에서 주간 11기관과 **기관명이 같은 파일**만 후보로 잡았다. 이름이 비슷한 기관은 넣지 않았다. 그 뒤 순서대로 확인했다.

1. 기관 일치 (파일명 기관명 + 본문)
2. 학년도 일치 — 연간: 본문 표기(「2025학년도」「27년 1월」 등)가 있으면 본문, 없으면 파일명 연도. 주간: 본문 날짜·요일 · 호수
3. 연령 · 반 일치 — **본문 기준**. 파일명 연령은 쓰지 않았다(아래 I01 사례)
4. 주간 기간이 연간의 그 달에 들어가는지 — §4 주차 규칙으로
5. 주제 연결 · 6. 활동 연결 — §6

**대상 매칭 등급**: `EXACT` 기관·학년도·연령·기간 일치 / `PARTIAL` 같은 기관인데 일부가 불명확 / `UNVERIFIED` 같은 대상인지 판단할 정보 부족 / `NO_MATCH` 대응 연간 없음.
**`EXACT` 는 대상 조건만 뜻한다.** 내용이 이어지는지는 §6 에서 따로 판정한다.

### 7-2. 월간 데이터 연결 후보 `[판단]` — 확정 매핑이 아니다

| 주간 항목 | 연간 자료와의 관계 `[실측]` | 월간 필드 후보 | 새 입력 필요 | 근거 |
|---|---|---|---|---|
| 주제 | 연간 월 주제와 `DIRECT` 다수, 기관 편차 큼 | `theme` (NONE) | 원칙상 불필요. 단 **교사가 주마다 바꾸는 경우가 흔하다**(§6-1) | I02 · I01 / I05 · I06 |
| 소주제 · 놀이주제 | 연간 주별 항목이 있는 기관에서 그대로 쓰임 | `focus[week]` (WEEK) | **v0.1.1 Template 은 `focus` 비활성** → 그 월간이면 생성 필요 | I02 · I01 · I03 |
| 바깥놀이 | 연간에 칸 없음 → **연간과 비교 불가** | `outdoor_play[week]` | — | §6-2 |
| 대체놀이 | 연간에 칸 없음 | `indoor_alternative` (비활성) | 생성 필요 | §3 10/10 |
| 안전교육 | 연간에 칸 없음 · 주간은 법정 영역 이름표 | `safety_education[week]` | — | §6-2 |
| 목표 | 연간 「선정 이유」에서 구체화(I09) | `goals` (NONE, 비활성) | 생성 필요 | §6-2 |
| 기본생활 | 연간에 칸 없음 | `habits` (WEEK, 비활성) | 생성 필요 | §6-2 |
| 행사 · 특별활동 · 준비물 · 알림 | 연간에 없거나 이름만 | `event_schedule` · `special_program` (비활성) | **교사 입력** | §6-3 |
| 실내놀이 · 대·소집단 | 연간 활동이 쓰이는 기관 일부(I07 · I05) | 대응 필드 없음 | 생성 필요 · 근거(Activity Catalog · Evidence) 확장. 생성 · 검사 경계는 ADR-014 를 따른다 | §6-2 |

### 7-3. 검증되지 않은 가정

- **월간 → 주간 연결은 실측으로 검증되지 않았다** `NOT_VERIFIED`. 같은 기관의 월간 · 주간이 짝으로 있는 곳은 I10 하나인데 그 주간이 이미지 PDF 다(BLOCKED).
  위 표의 월간 필드 후보는 「연간↔주간 실측 + 현재 월간 Core 구조」에서 나온 추정이다.
- **연간→주간 연결이 보인다고 월간 `CONFIRMED` Gate 를 건너뛸 수 있다는 뜻이 아니다.** Gate 정책은 §9 그대로 둔다.
- 「월간 `theme` = 연간 그 달 주제」는 월간 Core 의 설계이지 샘플 실측이 아니다.

## 8. Evidence Store 현황

**`p0-planning/data/evidence/institution_evidence_v0_1_0.json`** (빌드 2026-09-13) `[실측]`

| | 값 |
|---|---|
| 전체 | 출처 349 · 레코드 12,367 · `source_type` 전부 `INSTITUTION_SAMPLE` |
| 주간 출처 | **4** (글자층 3 · 이미지 1) — I07 · I08 · I09 · I10 |
| 주간 레코드 | **123** — `event` 43 · `indoor_play` 22 · `daily_routine` 18 · `week_experience` 13 · `outdoor_play` 12 · `safety_education` 9 · `indoor_alternative` 6 |
| 아직 수집 안 된 주간 파일 | **122** (I01 · I02 · I03 · I04 · I05 · I06 · I11 전부) |

**단위가 다르다.** PDF 1개 ≠ 출처 1개 ≠ 주간계획 1건 ≠ 레코드 1개. I02 는 PDF 하나에 주간계획 4~5건, I07 은 반 5개가 들어 있다.

**연결 필드는 이미 있다** — 레코드가 `institution_id` · `year` · `month` · `age_scope` · `page` · `source_sha256` 을 가진다.
다만 **`year` 가 학년도인지 달력 연도인지 정의가 필요하다**(§2 파일명 연도 혼재).

**개인정보.** 교사 이름 · 아동 실명(I05 행사 칸) · 계좌번호(I07 · I11) 가 칸 안에 섞여 있다. 수집하려면 칸 단위 제외 규칙과 사람 검토가 먼저다.

**생성 근거로 충분한가 — 아니다** `[판단]`. 실내놀이 22 · 대체놀이 6 레코드가 3개 출처에서 나왔다. 대·소집단 활동은 전용 섹션 레이블이 없다.

**후속 PR 제안** — Evidence Store 새 판(v0.2)으로 주간 122개 수집 · 섹션 매핑(§3 표기 → semantic_key) · 학년도 필드 정의 · 개인정보 칸 제외 · 사람 검토. 기존 판은 덮어쓰지 않는다.

## 10. W1 구현 준비

### 10-1. 확정된 사실 `[실측]`

- 주간 샘플은 1주 단위가 다수(9/10), 주제 · 기본생활 · 실내놀이 · 바깥놀이 · 대체놀이 · 가정 연계가 10/10.
- 대부분의 행은 주 전체 값 하나, 요일 값은 4개 행뿐.
- 주차 번호 · 월 경계 배정은 Core `canonical_week_periods` 와 일치.
- 연간→주간 주제 연결은 기관 편차가 크다(I02 86/87 ↔ I06 1/21).
- 특별활동 · 행사 날짜 · 준비물 · 알림 · 실행 기록은 연간에 없다.

### 10-2. W1 에서 확정해야 할 것

| 항목 | 상태 | 비고 |

| 생성 Gate — 월간 `CONFIRMED` 여야 주간 생성 | **CONFIRMED** | 루트 `CLAUDE.md` 「확정은 층마다 순차 게이트」 · `p0-planning/CLAUDE.md` 「A confirmed parent is required before creating a child plan」 · 요구사항명세서 §4.1 · FR-304 · api-spec 「층 순서를 건너뛸 수 없다」. 단 루트 `CLAUDE.md` 예시는 연간→월간만 적는다 |

## 11. 분석 한계

- **이미지 전용 1건**(I10)은 읽지 못했다.
- **공식 작성 지침이 없다.** 모든 구조는 샘플 관찰이다.
- **같은 기관 월간 · 주간 짝이 없다**(읽을 수 있는 것 기준). 월간→주간은 추정이다.
- **입수 경로가 기록돼 있지 않다.** I09 는 예시안일 수 있다.
- **표본이 치우쳐 있다.**
  - 기관: I04 · I02 두 기관이 파일 65/126 이다. 연간 매칭 `DIRECT` 131건 중 86건이 I02 다.
  - 연령: 3세 계획이 가장 많다.
  - 연도: 학년도 2025 가 대부분이고 2026 은 3월~10월분이다.
- **파일명 메타데이터가 틀린 경우가 있다**(§2). 연령 · 연도는 본문으로 확인했지만, 본문에 표기가 없는 연간(I01 · I03 · I07 · I08)은 파일명 연도를 썼다.
- 「주제 연결」은 **문구 비교**다. 교사 의도나 실제 진행은 알 수 없다.
