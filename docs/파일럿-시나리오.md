# 파일럿 테스트 안내 (교사·멘토용)

```
만든 날   2026-10-21
주소      https://ssample.duckdns.org
```

권장 순서는 **초기 설정 → 관찰일지 → 보육일지 → 연간계획안 → 월간계획안 → 평가 준비**입니다.
전체 약 30~40분을 예상하며, 시간이 부족하시면 **관찰일지와 보육일지를 먼저** 봐주시면 됩니다.

테스트에는 **가상의 원·반·아동 정보**를 사용해주세요.

---

## 1. 처음 접속 — 우리 반 설정

1. **회원가입** → 가입 후 **로그인하러 가기** → 로그인
2. 원 정보 입력 → **다음**
3. 반 이름·연령·담임 정보 입력 → 법정대리인 동의 체크 → **다음**
4. 가상 아동 이름 입력 → **+ 추가** → **설정 완료**
5. **우리 반** 화면에 등록한 정보가 표시되는지 확인

이미 설정한 계정이라면 다음 단계부터 진행하시면 됩니다.

> **관찰 기록을 적기 전에** 한 번 들러주세요 — **설정 → 관찰 영역 → 영역 구분** 에서
> 관찰을 어떤 갈래로 나눌지 고릅니다.
>
> ```
> 누리과정 5영역        신체운동·건강 · 의사소통 · 사회관계 · 예술경험 · 자연탐구
> 일상생활 · 놀이활동    두 갈래
> ```
>
> 원에서 쓰시는 관찰일지 양식에 맞추시면 됩니다. **이미 적은 기록은 그대로 남고**,
> 새로 적는 기록부터 바뀐 갈래를 씁니다.

---

## 2. 관찰 기록 → 관찰일지 만들기

1. 왼쪽 **관찰 기록** 클릭
2. 담당 반·아동·관찰 날짜·영역 선택
3. **실제로 관찰한 사실** 에 아래 내용 입력

   > 블록 세 개를 쌓은 뒤 친구에게 같이 만들자고 말했다.
4. **관찰 기록 저장**
5. 저장한 기록의 **관찰일지 만들기** 클릭
6. **초안 만들기**
7. **사실·해석·지원** 을 읽고, 해석이나 지원 내용을 직접 수정
8. 검토 확인란 체크 → **검토 완료 · 문서 확정**
9. **한글 파일로 내려받기** → 내려받은 `.hwpx` 파일 열기

확인 부탁드릴 부분: **입력하지 않은 행동이나 발언이 추가됐는지**, 해석과 지원이 관찰
사실에 맞는지, 교사가 수정하기 편한지입니다.

사실 칸은 이 화면에서 고칠 수 없습니다. **관찰 기록에서 고쳐 주세요 →** 로 원본 기록을
수정합니다. 원본을 고치면 그 기록을 쓴 문서가 **「다시 검토」** 대상이 됩니다. 확정본이면
**확정 취소** 를 먼저 누르고 **변경된 근거 반영하기** 로 바뀐 사실을 받아옵니다.

---

## 3. 일과 기록 → 보육일지 만들기

1. **우리 반 → 오늘 일과 적기**
2. 날짜 선택 — **어제로 선택해주세요** (7번 평가 준비에서 집계까지 보시려면)
3. 일과 입력
   - 일과 이름: `오전 실내놀이`
   - 시간: `09:00~10:00`
   - 활동계획: `자연물과 블록을 제공한다.`
   - 활동실행: `유아들이 블록으로 길을 만들고 자연물을 길 옆에 놓았다.`
4. **오늘 일지 만들기 →**
5. 문서에 사용할 일과 선택 → **초안 만들기**
6. 사실·해석·지원 검토 및 수정
7. 검토 확인란 체크 → **검토 완료 · 문서 확정**
8. **한글 파일로 내려받기** → 파일 열기

확인 부탁드릴 부분: **계획과 실제 실행이 구분되는지**, 실제 실행을 근거로 초안이
작성됐는지입니다.

활동실행이 비어 있는 줄은 고를 수 없습니다. 회색으로 두고 이유를 옆에 적습니다 —
적으러 가시려면 **일과 기록에서 고쳐 주세요 →** 를 누르시면 됩니다.

---

## 4. 연간계획안 생성·수정·다운로드

1. **계획 노트 → 계획안 만들기**
   기존 계획안이 있으면 **새 계획안 만들기**
2. **연간** 선택 → 반 정보 확인 → **계획안 생성하기**
3. 3월부터 다음 해 2월까지 월별 주제·소주제 확인
4. **내용 수정** → 원하는 달의 주제·소주제 수정
5. 해당 달의 **안전교육 입력** 펼치기
6. **이 달의 배치 계획을 입력했어요** 체크 → 교육 종류 선택
7. **수정 완료** → 새로고침 후 수정 내용 유지 확인
8. **연간계획안 확정 → 한글 파일로 내려받기**

확인 부탁드릴 부분: 연령·계절에 맞는 주제인지, 소주제가 실제 반 운영에 도움이
되는지입니다.

**확정 후에는 수정이 제한되므로 수정 테스트를 먼저 진행해주세요.**

---

## 5. 월간계획안 생성·수정·다운로드

확정한 연간계획안이 있어야 진행할 수 있습니다. 연간을 확정하신 자리에
**월간계획안 만들기 →** 가 바로 나옵니다.

1. **계획 노트 → 월간 양식 설정**
2. 사용할 항목 선택 → **○칸으로 양식 만들기**
3. **계획 노트 → 월간계획안**
4. 월 선택 → **○월 계획안 만들기**
5. 주차별 내용을 확인하고 여러 칸 수정
6. **수정 내용 저장** → 새로고침 후 유지 확인
7. 필요한 칸에서 **↻ 이 칸만 다시 만들기** 실행
8. 최종 검토 → **확정하기 → 한글 파일로 내려받기**

확인 부탁드릴 부분: 표가 읽기 편한지, 칸 입력이 편한지, **연간 주제와 월간 활동이
자연스럽게 이어지는지**입니다.

안전교육은 연간에 입력한 내용을 주차별로 자동 배치하지 않습니다. 빈칸은 직접
입력해주세요. **근거 없이 채우지 않는 것이 설계이며, 비어 있는 칸은 그 이유를 적어
둡니다.**

---

## 6. 저장한 문서·기록 다시 찾기

- **문서 보관함** → 확정한 관찰일지·보육일지 다시 열기 → 수정한 내용 유지 확인
- **기록 모아보기** → 날짜 선택 → 해당 날짜의 기록 확인
- **관찰 기록 → 아이별 모아보기 →** → 아동 선택 → 해당 아동의 관찰 기록 확인

---

## 7. 평가 준비 현황 확인

1. **평가 준비** 클릭
2. **확정 문서 자동 집계** 의 문서 현황 확인
3. **교사 자기 점검** 항목 체크
4. 새로고침 후 체크 상태 유지 확인

이 화면은 문서의 **종류·개수·기간**과 자기 점검을 보여줍니다.
**문서 내용의 적절성이나 공식 평가 통과 여부를 판정하는 기능은 아닙니다.**

자동 집계는 **어제까지의 자료**를 기준으로 합니다. 보육일지를 만든 직후 집계까지
확인하시려면, 3번에서 일과 날짜를 어제로 선택해주세요.

## 마지막으로

**막힌 클릭 위치, 이해하기 어려운 표현, AI가 덧붙인 사실, 실제 업무에서 불편할 부분**을
알려주시면 감사하겠습니다.

한글 파일은 내려받기와 파일 안의 내용까지 확인했습니다. 다만 **실제 한글 프로그램에서
페이지가 어떻게 나뉘는지, 인쇄했을 때 모양이 어떤지**는 아직 확인하지 못했습니다.
이번에 함께 봐주시면 좋겠습니다.
